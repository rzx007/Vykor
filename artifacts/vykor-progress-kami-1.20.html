核心变化

Vykor 正从“每个入口各自运行”转向“多个入口共享一份业务真相”。这让后台任务、跨会话协作和浏览器操作可以在同一条运行链路上衔接。

Kami 1.20.0 制作

新功能

  1. 共享后台

    让 Desktop、CLI 和 TUI 复用同一个本机后台，共享会话、任务与 Agent 状态。

  2. 跨会话观察

    允许当前 Agent 在授权后观察另一条持久会话的一轮运行，并短时等待状态变化。

  3. 浏览器复用

    让 CLI 发起的会话在条件满足时使用 Desktop 内嵌浏览器，无连接时不影响其他工具。

  4. 网页批注

    把网页元素批注、有限选择器和页面上下文随消息交给 Agent，减少反馈指向歧义。

  5. 桌面交互

    增加原生系统通知和消息链接打开方式选择，减少桌面应用之间的切换。

稳定性修复

  1. 结果隔离

    隔离浏览器超大回包，使单次工具错误不再拖累其他请求或整个后台。

  2. 状态统一

    统一子 Agent 的等待、完成和失败状态，并改善等待超时的判定。

  3. 退出收束

    为进程退出后的输出读取设置时间边界，避免命令结束后会话继续卡住。
