用户能感知的六项变化

基础设施Desktop 与 CLI 共用后台

会话、任务和 Agent 由同一个本机 daemon 持有；支持按需启动、登录自启、异常恢复，以及完整的 daemon 管理命令。

协作授权的跨会话观察

当前 Agent 可以固定观察另一条持久会话的一轮运行，读取状态，或短时等待其完成、请求审批或提出问题。

浏览器CLI 会话复用 Desktop 浏览器

当 Desktop 连接同一后台且目标会话已打开，CLI 发起的 Agent 也能使用内嵌浏览器；无浏览器连接时不影响其他工具。

反馈网页元素批注随消息发送

用户可选中页面元素、填写意见并统一管理批注包；Agent 收到批注、有限选择器和页面上下文，不需要猜测反馈指向。

桌面体验系统通知与链接打开方式

Desktop 增加原生通知交互；消息链接可选择在内嵌浏览器中打开，减少应用之间来回切换。

数据可靠性附件与子 Agent 状态更完整

更多附件可安全保存到工作区；会话压缩和重建后仍恢复引用，子 Agent 的等待、完成和失败状态也统一展示。

检查结论

  1. 版本落后六个次版本：GitHub Release 显示最新版本为 V1.20.0，发布时间为 2026-10-29；当前本地 VERSION 为 1.14.0。
  2. 自动更新检查未成功：技能要求启动任务时运行 bash scripts/check-update.sh，但 Windows PowerShell 将 Windows 路径直接交给 WSL Bash 时无法定位脚本。
  3. 脚本行尾不兼容：转换为 /mnt/c/... 后，脚本仍因 CRLF 行尾出现 set: -\r: invalid option，所以旧版无法可靠提醒更新。
  4. 内容能力本身完整：当前副本已包含中文 changelog 模板、内容 Schema、样式检查、占位符检查、PDF 渲染和视觉 QA 路径，可以完成本次交付。

建议动作

先升级到最新 Kami，再复测 Windows 下的每日更新检查。技能给出的通用更新命令是：

npx skills add tw93/kami -a claude-code codex cursor -g -y

如果新版仍只提供 Bash 脚本，建议上游增加 PowerShell 入口，或确保发布包统一使用 LF 行尾，并在技能说明中给出 Windows 路径转换方式。
