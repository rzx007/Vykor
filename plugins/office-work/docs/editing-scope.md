# 修改范围核对

官方 Skill 负责编辑方法；OfficeCLI 工具负责执行。需要证明“只修改指定内容”时，在编辑调用中传入 scope_targets；工具比较修改前与关闭后的工作副本，失败时不发布成果。

| 格式 | scope_targets | 核对边界 |
| --- | --- | --- |
| Word | /body/p[1]、实际 paraId 路径、表格单元格内段落或文字片段路径 | 掩去声明的节点后比较主文档 XML，保护其余正文、控件、节设置及其他文件部件；忽略核心保存元数据与生成的 textId，不忽略内容或格式 |
| PPT | /slide[3]/shape[@id=4] 等实际对象路径 | 保留原页面差异与对象检查，保护无关页、同页其他顶层对象和共享部件。表格为一个保护单位；整页路径授权整页变化，会明确标明 |
| Excel | /明细/B2 或 /明细/A2:B10 | 展开明确单元格，复用原有值、公式、样式及文件包结构保留检查，合计最多 2000 格；图表派生缓存允许变化，数据绑定受保护 |

这些检查只核对允许变化的范围，不证明请求文字正确、公式结果已重算或视觉通过。工具返回 change_check，包含实际声明范围、源与新文件摘要；Check 只附带当前摘要对应的记录。结构重排不用静态单元格或段落路径冒充核对；不声明范围时返回 scope_verified:false，按官方技能回读实际结果。

保留检查的边界：复杂 Word 跨部件操作、复杂 Excel 结构重排、合并区域非主格等情况可能无法核对而拒绝。Excel 原本没有样式表、首次写入生成样式表时，旧保留检查不能证明其他单元格的外观未变，会拒绝核对，不能放宽检查后仍声称范围通过。普通创建和编辑仍可通过原生命令执行，但必须如实报告未验证的范围。

仅对普通局部修改提供可选范围检查，不另建一套段落／图表编辑命令或逐属性业务规则。文件锁、工作副本、版本条件和原文件另存保护始终执行，与是否声明 scope_targets 无关。
