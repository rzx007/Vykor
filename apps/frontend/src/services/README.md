# 终端界面服务

[frecency.ts](frecency.ts) 记录命令和文件使用时间，并按时间衰减排序。`record()` 首次读取所选用户根的 `frecency.json`，内存数据和文件路径由当前模块持有；后续使用批量延迟保存。

`flushFrecency()` 取消定时器并立即写回首次读取绑定的路径；`closeFrecency()` 成功保存后释放内存数据和路径，下次使用会重新读取。保存失败保留待保存数据并把错误交给显式关闭调用方，避免悄悄丢失。宿主停用服务或进行迁移前应调用关闭边界；产品用户根在进程启动时固定，切根需要重启。

新界面服务放本目录，测试放 [__test__/](__test__/)。返回[包说明](../../README.md)。
