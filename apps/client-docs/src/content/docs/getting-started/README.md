# 快速开始内容

此分类帮助读者连接已有 daemon，并运行一次可以观察权限和最终状态的任务。

| 页面 | 用途 |
| --- | --- |
| [installation.mdx](./installation.mdx) | 安装、Node 与浏览器连接、模型和工作目录来源 |
| [first-run.mdx](./first-run.mdx) | 创建会话、提交输入、权限观察与指定 Run 等待 |

入口来自站点首页，先说明 daemon 需已配置，再展示公开 SDK。状态和结果仍由 daemon 保存。新增最短可运行流程放这里，专题操作放 `guides/`。完整代码引用 `examples/` 源文件，示例变量名和运行参数变动时同步检查文案。
