# Node 示例

这里是可直接由 Node.js 24 运行的脚本入口，参数和执行命令见[示例总览](../README.md)。

- `connect.ts`：连接已有 daemon，检查协议并列出会话。
- `run-with-permissions.ts`：在新会话中提交真实任务，拒绝权限请求，等待指定 Run 终态；失败或取消时请求中断后台运行。
- `sync-events.ts`：观察已有会话的快照和事件，最多 30 秒；只停止本地订阅。
- `files.ts`：读取会话在 daemon 机器上的工作区文件，不启动 Agent。
- `service.ts`：可选的本机服务管理；默认只发现，`--start` 和 `--stop` 才改变服务状态。

会话与运行记录属于 daemon，各脚本只保留连接参数和临时展示状态。新的独立脚本放在本目录，明确所需输入、网络等待上限以及需要清理的后台状态；不要依赖其他示例的导入副作用。
