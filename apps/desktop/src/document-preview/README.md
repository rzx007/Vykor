# 文档预览页面

此目录提供桌面文档预览使用的独立页面。`index.html` 加载 `main.ts`，后者等待父窗口发来的 `document:open` 消息，校验文件名、字节内容和大小后创建预览器。

`main.ts` 持有当前预览器，新文件打开或页面关闭时销毁旧实例；加载完成、错误和就绪状态通过 `document:loaded`、`document:error`、`document:ready` 消息返回父窗口。文件内容不在这里持久保存。

`style.css` 管理预览工具栏和页面外壳，默认正文字体与桌面界面一致；PDF、DOCX 等文件内部的字体仍由文档内容决定。父窗口传入的颜色写入 `--preview-*` 变量。

新增格式适配和预览外壳样式放在这里；父窗口的文件选择、授权和消息发送留在原功能模块。新增测试放在 `__test__/`。
