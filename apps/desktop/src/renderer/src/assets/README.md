# 桌面样式与静态资源

`main.css` 是 renderer 的唯一全局样式入口，由 `../main.tsx` 加载。它保留 Tailwind / shadcn 的导入、语义颜色和圆角映射、主题变量与全局基础规则；不要把业务页面样式重新堆回入口，也不要改写 shadcn 基础组件约定。

## 样式职责

- `main.css`：第三方样式及字体导入、Tailwind 源扫描、主题与全局基础。`--font-sans` 默认使用随应用提供的 Inter / Noto Sans SC，和 `--font-mono` 一起由外观偏好更新；独立的 `--font-chat` 使用同一阅读字体，不受用户切换界面字体影响。
- `markdown.css`：消息与文档预览共用的 Markdown 元素规则、文件引用、代码外壳、表格和 Mermaid。普通预览使用默认参数，`.assistant-markdown` 只覆盖阅读参数，避免再写一套同名元素规则。
- `workspace.css`：工作区、消息列、标题栏、终端及少量跨页面工具类。`.text-chat` 让输入框、用户消息和助手正文使用同一阅读字体。
- `motion.css`：内容入场、菜单提示及减少动态效果规则；不参与 Markdown 解析或字符动画状态。
- `notes.css`：便签颜色与纸面样式。
- `settings.css`：设置页的内容列、表单布局及窄窗口规则。
- `__test__/`：样式与真实 Markdown 输出的匹配检查。段落测试必须使用库实际输出的 HTML，不能只检查 CSS 中是否写了某个选择器。
- `audio/` 与同级图片：通知声音和应用静态图片。

## 运行与新增规则

样式在启动时按入口导入，外观偏好通过根变量实时更新。样式文件不保存会话状态；解析、流式输出、代码高亮与复制仍由对应组件负责。

Streamdown 2.5 的普通段落没有 `data-streamdown="paragraph"`。正文宽度和相邻段距使用 `.desktop-streamdown > p`，列表、引用和表格的段落单独处理。升级库时检查真实结构。新增的中文字体许可证保存在 `../../public/noto-sans-sc-OFL.txt`，构建时随静态资源复制。

新增跨页面样式按上面的职责归档。只供一个独立功能使用的样式与该功能放在一起，再由功能入口导入。新增字体随应用提供，不依赖远程字体服务。
