# 常规设置

对话显示、常用偏好、自动启动、编辑器和快捷键设置。

## 放置边界

适合轻量的常规偏好；形成独立复杂功能后移入专门分类，避免重新变成大杂烩。

编辑器偏好属于低频选项，放在常规设置的“高级选项”内，默认折叠。设置行使用统一的标题和分隔线，不重复解释名称或当前控件已经表达的含义。回复风格、进度通知和思考过程的补充说明通过标题旁的帮助入口查看；生效范围、风险、草稿保留和保存状态仍直接显示。

“回复风格”提供协作（默认）、直接、讲解，决定回复的表达方式与解释深度；“进度通知”单独控制关键节点同步或仅在必要时回复。两者分别保存为全局 `replyStyle` 与原有的 `workStyle`，兼容已有配置。`general-settings.tsx` 组合设置行，`general-display-controls.tsx` 读取桌面快照并立即保存选择；保存期间禁用控件，失败时恢复上次选择并显示错误。新增同类显示偏好继续放在该文件，复杂设置另建分类。

组件、模型、类型和 hook 按本功能共同维护。测试、测试辅助文件和基准测试统一放在同级 `__test__`，沿用被测功能的文件名。

## 主要文件

“消息链接打开方式”提供每次询问、Vykor 内置浏览器和系统默认浏览器；初始询问时预选内置。记住选择后可在这里切换浏览器或恢复每次询问，保存到本机桌面偏好，立即生效。
