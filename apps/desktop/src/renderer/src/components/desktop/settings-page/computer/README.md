# 电脑控制设置

入口在「设置 → 智能体 → 电脑控制」，也可以搜索「电脑操作」或「应用授权」。

[`computer-settings.tsx`](computer-settings.tsx) 向桌面主进程分别读取电脑控制设置和已保存的应用授权。状态来自系统平台、启动配置、本机偏好和驱动校验；后台连接在聊天发起任务时核对。开关以主进程确认后的状态更新，关闭电脑控制时等待键鼠释放。前台偏好从下次电脑操作任务生效。即使电脑控制暂时不可用，仍可查看和撤销本机已保存的授权。

开关和应用许可都保存在桌面本地偏好里。用户在聊天里选择「始终允许」时保存许可，设置页复用主进程的撤销入口，并以主进程返回的列表更新显示。「使用方法」提供可复制到主聊天的示例。状态和授权管理放在本目录，实际操作、审批和预览见[聊天电脑操作](../../tools/computer/README.md)。
