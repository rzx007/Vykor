# 电脑操作

`computer-interaction-dialog.tsx` 复用桌面的对话框和按钮，接收主进程发来的应用授权和目标选择。只有多个目标都符合时才选择。应用授权可选仅本任务或始终允许，页面反馈给请求发起方后继续同一步。

对话框挂在桌面根页面，断线或操作取消后收到关闭通知。是否可以操作、应用是否已授权及目标是否仍然有效由主进程核对。新增电脑操作的界面交互放在本目录，运行设置中的授权列表随运行设置维护。

[`computer-activity-panel.tsx`](computer-activity-panel.tsx) 放在当前主聊天的输入框上方。面板读取当前任务的应用、窗口、占用状态和读回结果。窗口画面在展开时显示，截图权限可随时关闭。暂停、继续和停止带上当前会话及运行的标识，由主进程再次核对。前台占用时显示本机急停键。切换会话、暂停或停止会立即清除本机预览。面板等待键鼠释放和后台截图撤回的回执，并在等待期间显示进度。
