# 工具分类

主界面工具面板承载的各类工具。

## 放置边界

工具的独立内容按功能放在子目录；标签、打开请求和面板缓存留在 layout/main-layout/utility-panel。

组件、模型、类型和 hook 按本功能共同维护。测试、测试辅助文件和基准测试统一放在同级 `__test__`，沿用被测功能的文件名。

## 子分类

- [智能体工具](agents/README.md)：智能体任务列表、任务分组和会话定位。
- [浏览器工具](browser/README.md)：内嵌浏览器导航、样式注入、截图与标注。
- [代码上下文](code-context/README.md)：代码选区的格式、元数据和添加到输入框的动作。
- [代码编辑器](editor/README.md)：虚拟化代码展示、编辑草稿、保存和布局模型。
- [文件浏览](files/README.md)：文件树、面包屑、搜索、文件预览和文件类型图标。
- [差异评审](review/README.md)：补丁加载、差异展示、改动导航、选区和已审阅标记。
- [工具共享展示](shared/README.md)：多个工具共同使用的轻量占位等展示。
- [侧边聊天](side-chat/README.md)：临时侧边会话、引用选区和独立草稿交互。
- [终端工具](terminal/README.md)：终端展示、会话输入、偏好、主题和链接处理。
- [工作流工具](workflows/README.md)：工作流摘要、任务图、过程和结果展示。

## 维护约定

新增独立子功能时同步补充 README 和父级导航。移动文件时更新导入、动态导入与测试 mock，不保留旧路径转发文件。完整规则见 [Desktop 协作约定](../AGENTS.md)。
