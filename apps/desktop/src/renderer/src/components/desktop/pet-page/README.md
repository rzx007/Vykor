# 桌面宠物页面

宠物页面的展示与交互入口。

## 放置边界

页面组件放在这里；宠物资源和底层服务保持各自已有归属。

组件、模型、类型和 hook 按本功能共同维护。测试、测试辅助文件和基准测试统一放在同级 `__test__`，沿用被测功能的文件名。

## 主要文件

- [pet-page.tsx](pet-page.tsx)：持有当前头像的随机身份和单击计时器，订阅主进程转发的宠物点击；单击延迟 280 毫秒切换头像，双击取消待定单击并打开主窗口，卸载时清理计时器和订阅。

头像展示复用 [AoraAvatar](../shared/aora-bot/README.md)，页面只传入当前身份和尺寸。窗口拖拽继续由外层按钮处理；窗口位置、置顶和鼠标穿透状态仍由主进程管理。
