# 桌面布局

窗口框架、主界面、设置界面与面板布局。

## 放置边界

只负责页面如何排列和切换，页面具体业务留在对应页面目录。

组件、模型、类型和 hook 按本功能共同维护。测试、测试辅助文件和基准测试统一放在同级 `__test__`，沿用被测功能的文件名。

## 子分类

- [主界面布局](main-layout/README.md)：主界面组合入口、上下文和面板切换。
- [设置页面布局](settings-layout/README.md)：设置页框架、导航侧栏和内容区域排列。
- [布局共享逻辑](shared/README.md)：多个布局共同使用的面板尺寸等逻辑。
- [窗口标题栏](window-chrome/README.md)：标题栏及桌面窗口边框相关行为。

## 维护约定

新增独立子功能时同步补充 README 和父级导航。移动文件时更新导入、动态导入与测试 mock，不保留旧路径转发文件。完整规则见 [Desktop 协作约定](../AGENTS.md)。
