# 消息数据整理

把会话消息、片段和运行记录整理成界面可用的数据。本目录维护转换与读取逻辑，不渲染组件、不保存会话，也不发起工具或网络请求。

| 文件                                                     | 职责                                                 |
| -------------------------------------------------------- | ---------------------------------------------------- |
| [message-content.ts](message-content.ts)                 | 读取正文、工具文本输出和子任务标识                   |
| [message-render-model.ts](message-render-model.ts)       | 整理助手展示条目、工具状态与摘要、文件变更和文件引用 |
| [conversation-turn-model.ts](conversation-turn-model.ts) | 将消息与运行记录整理成对话回合和系统条目             |
| [reasoning-text.ts](reasoning-text.ts)                   | 按已有展示上限裁剪推理文本                           |

blocks、transcript、工具详情和状态提示直接调用对应文件中的函数，传入消息片段或运行记录，再消费返回的展示数据。转换过程的集合和计数只属于本次调用，原始会话与运行状态由外部存储管理。历史结果仍只用于读取已有记录。

新增与消息数据有关的纯计算放在对应文件；组件状态放 blocks，工具执行和会话保存留在宿主。测试放同层 [测试目录](__test__/)，回合与滚动组合的测试仍由 transcript 维护。返回[消息展示导航](../README.md)。

Markdown 渲染单元保留来源消息与片段 ID；同一条消息内同阶段的连续文本仍合并，跨消息保持独立，供搜索准确定位实际正文。
