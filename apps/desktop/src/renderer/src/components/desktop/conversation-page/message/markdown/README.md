# Markdown 消息渲染

Markdown、代码块、图表和流式渲染适配。

## 放置边界

渲染插件、修复逻辑与基准测试归此类；独立文件编辑器放在 tools/editor。

组件、模型、类型和 hook 按本功能共同维护。测试、测试辅助文件和基准测试统一放在同级 `__test__`，沿用被测功能的文件名。

## 主要文件

- [assistant-markdown.tsx](assistant-markdown.tsx)
- [streaming-markdown-block.tsx](streaming-markdown-block.tsx)：保留 Streamdown 的块和语法树，只在解析后的新增文本叶子上创建淡入节点；历史稳定块直接复用原组件。关闭动画时从解析流程移除动画插件，不改变块组件结构；重新开启先用当前正文建立基线，再动画显示后续追加文字。
- [streaming-text-animation.ts](streaming-text-animation.ts)：每块独立保留最近最多 512 个动画字符的位置，追加时淘汰更早的包裹，停顿 150ms 后整批恢复普通文本；每个活动块最多一个清理计时器，不再分配全局逐字额度或记录逐字过期时间。清理只更新文本叶子，不重新解析 Markdown。长回复动画没有 4096 字符限制，正文的 64ms 合并刷新与代码源码更新策略保持不变。
- [incremental-markdown.ts](incremental-markdown.ts)
- [markdown-emphasis.ts](markdown-emphasis.ts)：在本次解析的 `<em>` 内标记中文片段，保留英文、链接、嵌套强调及原始文字；跳过代码、键盘输入、公式和 SVG。
- [mermaid-diagram.tsx](mermaid-diagram.tsx)

正文排版由 [assets/markdown.css](../../../../../assets/markdown.css) 统一负责，通过 [main.css](../../../../../assets/main.css) 导入。普通预览和消息共用一套元素规则，`.assistant-markdown` 通过参数选择标题、段落、列表、引用和表格的阅读密度。普通顶层段落最多 `40em`；Streamdown 2.5 输出没有专属标记的 `<p>`，使用 `.desktop-streamdown > p` 设置宽度和相邻段距，不再依赖 `data-streamdown="paragraph"`。列表、引用和表格内的段落单独处理，代码块和表格保留外层消息列宽。

消息正文独立使用 `--font-chat`（随应用提供的 Inter / Noto Sans SC），默认 `16px / 1.7`，相邻段距 `0.8em`；文档预览继续使用界面字体，代码沿用 `--font-mono`。支持时开启中英自动间距，代码、文件引用和表格显式排除。排版不改写消息或复制内容，也不随流式状态切换；回合高度继续由 transcript 的虚拟列表测量并处理滚动补偿。辅助文字使用的共享小字号变量保留 `12px` 下限。

`streamdown-plugins.ts` 在默认内容清理后接入中文强调处理，只给 `<em>` 内的中文及全角标点增加显示节点。外层 `<em>` 保留，中文通过 CSS 直立并加重，英文继续使用斜体；汉字与异体字选择符保持完整。`streamdown-components.tsx` 用语义化的 `<strong>` 展示加粗，保留原有样式标记。行内代码和文件引用不继承斜体；正文约束中文标点换行，技术内容沿用原规则。处理不增加组件状态或流式定时器，稳定段落继续由原有分块缓存复用。

## 维护约定

动画不切分 Markdown 源码，不接管解析、高亮或复制；跳过代码、公式、SVG 等内容。动画开启时，当前块的旧文字仍参与正文基线比较，但不重复分字，也不为动画范围之前的片段分配候选记录；只有与现存动画字符相交的叶子才增加动画组件。新字符用 `Intl.Segmenter` 保持 emoji 和组合字符完整。初次收到大量段落时，已稳定的段落直接显示，只为末尾块创建动画状态；单批超额部分直接显示，不排队。连续换段时，前一个块可以短暂收尾，各块互不抢占额度；节点和计时器随近期活动块数变化，不随历史正文长度积累。清理只通过块内 React 上下文更新实际包装的文本叶子，不通知普通旧片段，无外部订阅或共享调度器。关闭动画期间不运行动画插件、不跟踪正文基线；修正、截断、关闭动效和完成时停止动画，卸载释放定时任务和正文基线。独立块的解析插件使用不同缓存标识，避免 Streamdown 的共享处理器缓存混用块状态。超长单段落、列表等活动块的 Markdown 解析开销仍随块大小变化，512 字符上限不代表整个渲染过程开销恒定。

新增独立子功能时同步补充 README 和父级导航。移动文件时更新导入、动态导入与测试 mock，不保留旧路径转发文件。完整规则见 [Desktop 协作约定](../../../AGENTS.md)。
