# 对话记录与滚动

记录排列、虚拟列表、滚动定位、预览轨道和待提交提示。

## 放置边界

负责整段记录的显示与定位；单条消息的细节留在 message。

消息图片由 `ConversationTranscript` 提供连续浏览范围：只在点击时从本记录已加载的 `messages`、`parts` 收集已完成图片附件，按消息与片段序号排列并按资源去重，包含虚拟列表当前未挂载的图片，不新增查询或订阅。图库归属取记录里的真实会话 ID；主聊天和侧聊显式传入反馈输入框作用域，子任务等未提供作用域的记录保持只读。文件预览、截图继续单张打开；找不到点击图片时也以只读单张回退。

组件、模型、类型和 hook 按本功能共同维护。测试、测试辅助文件和基准测试统一放在同级 `__test__`，沿用被测功能的文件名。

## 维护约定

新增独立子功能时同步补充 README 和父级导航。移动文件时更新导入、动态导入与测试 mock，不保留旧路径转发文件。完整规则见 [Desktop 协作约定](../../AGENTS.md)。

本地发送失败行的“核对并重试”调用 store 恢复动作，先查原输入 ID 再决定是否重发。关闭提示只隐藏本地行，保留去重记录，避免再次点击发送时创建重复任务。运行错误可以定位原消息并打开现有编辑框，进入编辑不会提交消息。

## 阅读与展开状态

主聊天与侧聊共用 `ConversationScrollerProvider`。滚动位置、跟随意图、新内容提示及展开偏好只保存在当前聊天的滚动控制器中，切换聊天重新建立；不写入消息或持久化存储。`ConversationTranscript` 在记录实际更新时标记新内容，返回底部清除提示。工具输出内部能够接收的滚动不改变外层跟随意图。

`turnExpansion` 同时记录过程与工具详情的展开选择，使虚拟行重新挂载后仍保持阅读状态。运行完成时沿用现有过程折叠；正在阅读、选中文字或操作详情时保留展开。完整工具结果仍只在展开后按需读取，不会重新执行工具。

任务状态直接读取现有运行、片段和待确认请求。生成与思考沿用 `conversationActivity`，等待确认优先于普通运行提示；完成、失败和停止沿用 `taskTimingLabel`。

返回按钮只常驻“回到最新”：左侧图标在运行时为缓慢旋转指示，等待确认为静态图标，空闲时为向下箭头；无运行时的新内容用静态小点。具体状态与新内容提示放在支持悬停、键盘聚焦的 Tooltip 和读屏名称中；减少动态效果时停止旋转。

历史行的高度补偿只作用于阅读点上方的整行；用户正在向上滚动时，不因上方行重新测高而反向移动视口。正在阅读的长回复向下增长也不拉动阅读点。回归同时由模拟滚动测试和隐藏 Electron 场景验证。

## 搜索与消息定位

`ConversationFind` 复用现有查找控件处理当前聊天的 Ctrl/Cmd + F、Enter / Shift + Enter 和上下条匹配消息；状态只存在本聊天，主聊天与侧聊分别处理自己的键盘焦点。`conversation-find-model.ts` 在已加载的用户与助手公开正文中匹配所有关键词，按消息计数；工具原始结果和隐藏思考不进入查找。

全局结果沿用返回的消息 ID，先通过现有虚拟列表定位并挂载历史行，再展开命中的过程或长用户消息。Markdown 单元保留所属消息与片段 ID，高亮只作用于对应正文；使用浏览器 Range / CSS Highlight，不插入文本节点、不改写 Markdown 或复制原文。重复选择同一结果也会重新定位，关闭查找会清除高亮。
