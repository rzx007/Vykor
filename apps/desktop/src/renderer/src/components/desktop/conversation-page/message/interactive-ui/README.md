# 交互界面（Beta）

支持可筛选表格、远程图片、嵌入视频和本机 HTML 预览。对话记录从正在运行或已完成的请求及对应输入中核对是否启用了 `vykor-ui-v1`。Markdown 渲染器在生成中传入代码块，表格列名完整后显示表头，逐行加入已经写完且通过校验的数据。流式回复识别到 `Video` 或 `HtmlView` 后先显示占位，图片、视频和 HTML 卡片在代码块闭合并通过校验后才加载。校验失败或回复结束时仍未闭合，显示原代码块。

- `interactive-ui-block.tsx` 是代码块入口。它持有当前表格的解析器，把逐步确认的数据交给同一个表格，并将闭合围栏交给富内容解析器。
- `openui-library.ts` 注册 `FilterableTable`，使用 OpenUI 的流式解析器。桌面只接受一个使用字面量参数的组件，显示前校验参数和行列大小。
- `filterable-table-stream.ts` 从原文提取写完整的标题、列和行，避免显示解析器补全的半截值。
- `filterable-table.tsx` 使用 Vykor 控件显示表格。筛选和排序留在当前组件，重新打开历史时从原消息恢复表格数据。
- `parse-rich-ui-content.ts` 读取一行字面量调用，使用桌面主进程共用的参数校验。图片接收 HTTP 或 HTTPS 地址，视频接收 HTTPS 地址，HTML 接收一份可独立运行的源码。主进程核对远程内容的公开来源。
- `rich-ui-content.tsx` 保存单张卡片的加载状态。常规设置默认关闭富内容，开启后卡片进入可见区域时自动请求加载，等待时显示占位。主进程再次检查设置，返回本机图片数据或隔离页面的挂载 ID。
- `rich-ui-preview.tsx` 提供共用的圆角预览区和等待提示。视频在生成、加载和显示时均使用 16:9，HTML 沿用受窗口高度约束的预览区，图片加载后按原始比例显示。

表格外框随聊天内容列缩放，最大宽度沿用 `--chat-content-width`，滚动区高度取 24rem 和窗口高度 55% 中的较小值。列按内容取宽，表头和单元格保持单行。鼠标或键盘可以在表格内横向、纵向滚动，纵向滚动时表头固定。筛选使用桌面共用的胶囊搜索框，清除筛选后焦点回到输入框。

本机开关由主进程保存，消息和运行状态由后台保存。关闭富内容时，当前挂载的卡片保留已加载的内容。离开卡片或内容变化后，旧页面地址交还主进程以撤销。新增组件的参数、允许提前展示的数据与界面在这里维护，提示说明放在 `@vykor/prompts`。逐行校验见 [解析测试](__test__/filterable-table-stream.test.ts)，聊天入口见 [会话测试](../../transcript/__test__/transcript.interactive-ui.test.tsx) 和 [富内容测试](../markdown/__test__/assistant-markdown.rich-ui.test.tsx)。
