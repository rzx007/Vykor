# 对话页面

主对话入口及输入、消息、记录和会话控制。

## 放置边界

根目录保留页面组合与公开入口，具体功能进入下级分类。

组件、模型、类型和 hook 按本功能共同维护。测试、测试辅助文件和基准测试统一放在同级 `__test__`，沿用被测功能的文件名。

## 主要文件

- [conversation-page.tsx](conversation-page.tsx)
- [index.ts](index.ts)

## 子分类

- [对话输入](composer/README.md)：富文本输入、提及、附件、选择器和提交行为。
- [消息展示](message/README.md)：用户与助手消息的组合、展示模型和交互。
- `对话插件界面`（旧实现已移除）：插件卡片、嵌入页面、桥接与显示生命周期。
- [对话会话控制](session/README.md)：新对话入口、会话菜单、摘要和任务定位。
- [对话共享代码](shared/README.md)：对话内跨功能复用的类型、文字操作和展示偏好。
- [对话记录与滚动](transcript/README.md)：记录排列、虚拟列表、滚动定位、预览轨道和待提交提示。

## 维护约定

新增独立子功能时同步补充 README 和父级导航。移动文件时更新导入、动态导入与测试 mock，不保留旧路径转发文件。完整规则见 [Desktop 协作约定](../AGENTS.md)。
