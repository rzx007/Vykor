# 图片查看与标注

图片来源、查看器、面板和标注状态。

## 放置边界

图片查看和标注的完整交互放在这里，消息附件与浏览器只负责调用入口。

组件、模型、类型和 hook 按本功能共同维护。测试、测试辅助文件和基准测试统一放在同级 `__test__`，沿用被测功能的文件名。

## 主要文件

- [image-viewer.tsx](image-viewer.tsx)
- [image-viewer-provider.tsx](image-viewer-provider.tsx)
- [image-viewer-panel.tsx](image-viewer-panel.tsx)
- [image-source.ts](image-source.ts)：读取附件、项目文件或内存图片；把不支持的格式和超过预览大小限制的情况与临时读取失败区分开。
- [image-gallery.ts](image-gallery.ts)：点击时从调用方已加载的消息或待发送附件收集同组图片，按顺序去重；不额外订阅全量聊天或提前读取图片。

同一聊天的消息图片共用一个连续浏览标签，未发送附件单独成组；侧边聊天和子任务使用自身数据。图库只是打开时的快照，当前图片仍保存在原面板标签中。上一张、下一张和焦点位于查看器时的方向键只更新当前来源，首尾不循环；输入批注、绘制或拖动时不占用方向键。读取失败仍可继续切图。

切图前同步读取并保存最新批注；保存失败或图片操作尚未完成时留在原图。切换后重建查看器，重置缩放、选区和绘制状态，批注仍按图片内容恢复。加入草稿沿用调用方的聊天范围，并在异步读取标记图片前后检查侧聊是否仍有效；没有可写草稿归属的子任务图片只允许查看、批注和导出。

画布滚轮由查看器就地处理：统一滚动单位，按当前比例缩放并限制单次幅度，保留光标下的图片位置。关闭缩放库自带的滚轮处理以避免叠加；拖动、触摸捏合、按钮和键盘缩放继续复用原组件。

读取失败时，面板就近提供“重新读取”；重读期间显示读取状态，同一次读取尚未结束时不重复请求。不支持的格式或超过预览大小限制时只说明原因。每次读取沿用面板版本号，并核对图片来源与聊天归属，切换图片、聊天或关闭面板后忽略旧结果；读取和重读都不上传附件、不发送聊天，也不改变批注加入草稿的归属。
