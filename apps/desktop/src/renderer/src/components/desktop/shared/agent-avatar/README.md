# 子智能体头像

聊天派发条目、子智能体列表和详情标题共用的低饱和行星头像。

## 入口与生成

- [agent-avatar.tsx](agent-avatar.tsx)：复用现有 Avatar 组件，提供 20、24、32px 三种尺寸。头像是任务名称旁的装饰，不重复朗读名称。
- [agent-avatar-source.ts](agent-avatar-source.ts)：使用固定版本的 DiceBear Core 和单独的 Planets 定义，在本地生成 SVG data URI。配色保持原色相和明度，饱和度为原来的 65%；透明背景、无星点和卫星、仅细星环，不播放动画。

所有入口使用持久的任务 `id`，不使用名称、列表下标、任务状态或临时随机数。派发结果已返回任务 ID、任务列表尚未到达时，聊天入口直接使用结果中的同一个 ID；尚未生成任务 ID 时保留通用图标。详情即使暂时丢失任务信息，也保留选中的任务 ID。

生成与缓存都在渲染进程内，不发网络请求、不写用户设置。缓存最多保留 256 个结果；移出缓存后仍按同一 ID 生成相同结果。头像不承担运行状态，状态文字与加载图标由各入口保留。

## 来源与检查

[DiceBear Planets](https://www.dicebear.com/styles/planets/) 采用 CC0 1.0；Core 采用 MIT。源码固定使用 10.6.0，避免依赖升级无意改变现有头像。这里的颜色属于插图配色，页面容器和状态继续使用主题变量。

同级 `__test__/` 覆盖本地输出和缓存后的稳定性；[跨入口测试](../../__test__/agent-avatar-surfaces.test.tsx) 覆盖三处一致、任务到达、状态变化、重新挂载和同名任务区分。新增头像相关代码放在本目录，不扩展到任务执行或持久状态。
