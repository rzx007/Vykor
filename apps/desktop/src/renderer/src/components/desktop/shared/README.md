# 桌面共享展示

多个桌面功能共同使用的轻量展示组件。

## 放置边界

仅放确实跨分类复用的展示，不接管页面状态或堆放无关工具函数。

组件、模型、类型和 hook 按本功能共同维护。测试、测试辅助文件和基准测试统一放在同级 `__test__`，沿用被测功能的文件名。

## 主要文件

- [desktop-empty-state.tsx](desktop-empty-state.tsx)
- [agent-avatar](agent-avatar/README.md)：聊天条目、子智能体列表和详情共用的本地低饱和行星头像，按任务 ID 固定外观。
- [aora-bot](aora-bot/README.md)：宠物和新对话起始页共用的本地 SVG 头像。页面持有随机标识与操作状态，适配器创建和清理动画实例。

## 维护约定

新增独立子功能时同步补充 README 和父级导航。移动文件时更新导入、动态导入与测试 mock，不保留旧路径转发文件。完整规则见 [Desktop 协作约定](../AGENTS.md)。
