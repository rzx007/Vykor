# 桌面后台服务启动

这里维护桌面系统常驻开关和无窗口启动入口。窗口进程使用 SDK 查找或按需启动后台。

- `daemon-entry.ts` 识别常驻、看护和按需模式。看护先判断登记进程是否还活着。常驻和按需模式都调用共享注册后台，并在启动前传入系统首选显示语言。
- `daemon-autostart-service.ts` 管理桌面常驻开关和系统启动项。设置状态由用户配置和操作系统保存。
- `daemon-surface.ts` 判断登记地址是否指向本机。 `ipc.ts` 注册界面的常驻开关入口。

测试覆盖启动模式和语言初始化。新增后台启动行为放本目录，会话连接放相邻的 session 目录。

无窗口启动向后台显式传入规范 workspaces 根，让系统常驻和按需后台中的无项目定时任务与窗口聊天使用同一目录。渠道装配独立使用规范 channels 根。
