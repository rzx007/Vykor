# 技能页面服务

`skill-service.ts` 接收技能快照、官方市场目录、安装和删除请求，通过 `skill-resource.ts` 使用已认证连接调用后台。市场安装使用用户选定的个人或项目范围，完成后返回最新的技能和项目列表。安装请求提交后连接中断时，刷新已安装列表可以确认结果。

旧后台缺少市场路由时，目录查询返回 `null`，桌面提供安全重启入口。已接入市场的后台遇到网络或索引错误时，返回对应的请求错误供页面显示。

后台持有技能文件与项目记录；本层只持有显式注入的数据根选项，不缓存技能状态。返回前按规范 workspaces/channels、迁移映射、暂存/保留根和旧版“文档/Vykor/日期/xN”路径过滤项目，以及这些项目下的项目技能；真实用户项目和个人技能保留原位置。

新增同类页面服务逻辑放在这里，新测试放在同级 `__test__/`；现有 `skill-service.test.ts` 覆盖筛选与连接重试。
