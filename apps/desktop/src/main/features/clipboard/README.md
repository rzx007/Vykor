# 剪贴板和文本菜单

`ipc.ts` 注册剪贴板文字读写和原生文本菜单入口；界面通过预加载的固定 IPC 通道调用，不直接访问系统剪贴板。

可编辑区域使用 Electron 原生剪切、复制和粘贴角色。Electron 44 的剪贴板读取是异步接口，因此打开编辑菜单前通过 `clipboard.read()` 检查是否有可粘贴内容；读取失败时禁用粘贴。只读消息菜单不读取剪贴板，只返回复制或当前对话内全选动作。

此目录不保存剪贴板内容或菜单状态，菜单关闭后将本次动作返回给调用页面。`ipc.test.ts` 覆盖文字菜单、图片粘贴、空剪贴板和输入校验；新增测试放在 `__test__/`。
