# 桌面便签

`ipc.ts` 接收便签页、快捷入口和选区保存的请求。`note-service.ts` 校验内容、版本和文件 ID，依次执行读取、保存、删除、整理和备份。冲突仍返回原错误格式，界面可以保留恢复稿或另存为便签。

`desktop-note-repository.ts` 打开当前数据根的 `data/desktop/notes/`。正文是 Markdown，索引和组织记录同目录保存。打开文件夹只使用桌面确定的路径，平时读写无需 daemon。

`legacy-note-import.ts` 在首次打开前检查导入收据。升级需要核对旧后台登记和进程身份，等待后台确认任务已收尾，再用控制锁和后台登记所有权阻止并发启动。导入器读取已停止的旧库与 Markdown，在新目录校验并原子发布，旧文件保留。若来源指向另一数据根，先完成整根迁移。已有导入收据的便签直接打开。

窗口关闭先等待界面回执，再等待主进程便签队列。退出和整根迁移还会关闭本地索引。整根迁移前，同步外部 Markdown 编辑和组织记录。统一备份使用同一队列中的 `backupTo()`。新增便签操作放本目录，测试放在 `__test__/`。
