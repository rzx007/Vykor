# 聊天富内容（Beta）

聊天卡片的加载按钮通过 [IPC 入口](ipc.ts) 请求主进程加载。入口核对主窗口及本机开关，再校验组件参数。开关只决定新的请求，已经加载的内容随卡片或窗口退出释放。

[图片加载](image-fetch.ts) 支持公开网络的 HTTP 和 HTTPS 位图。每次重定向都重新检查地址。有系统代理时通过代理请求，直连时固定已检查的 DNS 地址。最多读取 5 MB，主窗口使用返回的本地数据 URL 显示图片。

[视频](video.ts) 接收公开 HTTPS 视频直链或站点提供的播放器地址。常见的 YouTube 和 B 站观看链接会转成官方播放器地址。视频和 HTML 都复用 [隔离文档](../plugin-apps/document-store.ts)。视频模块处理播放器需要的请求头，预览以一次性的挂载 ID 交回窗口。视频使用独立播放器页面，HTML 内联脚本在离线页面运行。每个窗口有 4 个聊天预览名额，与插件应用的名额独立。

新增内容类型先在 [跨进程参数](../../../shared/rich-ui-content.ts) 定义，再在本目录实现新的加载方式。测试放在 `__test__`。
