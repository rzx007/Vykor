# 桌面插件服务

负责桌面插件列表和管理、普通归档与 Git 安装、市场浏览和安装确认。渲染页面通过 `ipc.ts` 调用主进程，所有插件记录和实际安装操作交给后台服务。

- `plugin-service.ts`：读取和管理已有插件；归档安装只接受当前项目目录，由系统文件选择器决定归档路径。预览后需要权限或替换确认时，把待确认信息暂存在主进程，页面只收到选择编号；确认后使用已保存的路径、摘要和权限安装，返回结果及最新列表。
- `marketplace-service.ts`：预览市场候选项，按发起窗口保存确认状态，通过后台操作回执查询安装结果。
- `selection-store.ts`：保存有有效期、只能消费一次的归档和 Git 确认选择；退出时清理临时选择，不删除已安装插件或用户数据。
- `icon-loader.ts`：为插件列表和详情读取图标。
- `__test__/`：服务、IPC 和安装包资源的回归测试；测试跟随所覆盖的模块放在这里。

研究与写作和演示文稿插件走市场或普通归档安装，不查找应用内的插件 ZIP。已有插件记录按普通插件继续管理。宿主文档功能使用的 `office-engine` 仍由桌面构建准备，并随应用单独分发；它与插件安装入口分开。

新增插件安装或管理能力放在本目录；渲染页面放在 `src/renderer/src/components/desktop/plugin-page/plugins`，跨进程请求和结果类型放在 `src/shared/plugin-types.ts`。
