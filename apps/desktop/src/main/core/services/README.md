# 窗口与生命周期服务

本目录保存主进程共用的窗口实例与应用退出流程。

`window-manager.ts` 的 `WindowManager` 创建和登记窗口，按 `main`、`pet` 身份保存实例，关闭后清理登记。`getMain()` 返回会话窗口；`getNotificationFocusWindow()` 为通知发送提供实际聚焦窗口，但排除只展示桌面宠物的已登记实例。这样隐藏或最小化主窗口时，宠物拿到焦点不会被误认为用户正在查看授权请求。宠物原有点击、拖动和聚焦行为不变。

窗口加载先清理开发环境的过期缓存，再打开对应路由；正式版本直接加载打包页面。窗口状态由管理器实例保存在内存中，业务模块通过应用上下文读取，不从标题或页面文字猜测窗口身份。

新增通用窗口规则放在本目录，具体功能窗口仍放在 `features/` 所属分类。新测试放同层 `__test__/`；跨通知、窗口与活动状态的回归位于 `main/__test__/permission-notifications.integration.test.ts`。
