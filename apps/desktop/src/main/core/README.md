# 主进程基础能力

本目录负责桌面启动上下文、窗口管理和进程生命周期。入口是上级 `index.ts`，它先配置运行环境，再等待 Electron 就绪并创建窗口。

- `app-context.ts`：创建运行路径和应用上下文，供主进程功能读取；窗口状态由上下文中的窗口管理器保存。
- `linux-input-method.ts`：在 Electron 就绪前启用 Linux 的 Wayland 输入法连接，让系统输入法向输入框提供候选词和中文。保留用户指定的显示后端，X11、Windows 和 macOS 继续使用各自的输入方式。函数只设置启动参数，不保存额外状态。
- `ipc/`：注册界面与主进程之间的调用处理器，结果通过对应调用返回界面。
- [services/](services/README.md)：管理窗口实例和应用退出流程；窗口管理器统一判断哪些窗口的焦点能够抑制系统通知，桌面宠物不属于会话查看窗口。
- `__test__/`：基础启动配置的回归测试。

新的通用启动配置放在本目录；具体业务功能放在上级 `features/` 对应分类中。

输入法修改需要完全退出并重新启动应用后生效。自动化测试检查启动参数和平台隔离；候选词显示与实际中文输入需要在运行系统输入法的 Linux 桌面会话中确认。
