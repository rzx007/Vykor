## 产品范围

Vykor 是围绕本地项目、会话和智能体任务工作的桌面开发工具。设置优先解决以下问题：

- 我修改的设置是否保存，何时生效，当前任务是否会受影响。
- 智能体是否需要批准，哪些文件、工具和网络访问受到限制。
- 命令和终端实际在本机还是 Windows 的 Linux 环境中运行。
- Git、模型连接和后台服务出问题时，如何检查和恢复。
- 会话、附件、记忆和日志占用了多少空间，如何安全清理和备份。
- 模型消耗了多少 Token，费用数据是否完整。

设置不承担项目内的提交、推送、分支切换和任务管理。这些操作保留在项目、Git 面板和会话中。设置提供它们采用的默认值和长期偏好。

不新增云账户、订阅购买、支付、社交分享或排行榜。个人资料只管理本地显示身份；费用页展示模型服务用量，不模拟 Vykor 的收费体系。桌面宠物、界面语言切换和提示词建议不属于本次完整设置范围，移除尚未接通的控件；应用继续使用现有中文界面。

## 所有页面共同遵守的规则

### 保存与读取

简单开关和选择器自动保存。复杂文本、规则编辑、配置导入和多字段操作使用明确的“保存”或“应用”按钮，取消不改变已保存值。

一次保存按以下顺序完成：界面提交变更，负责该项设置的服务校验并保存，服务返回真实保存值与生效状态，界面根据返回结果更新。界面中的临时值不是保存成功的依据。

- 首次读取使用加载状态，不用默认值伪装读取成功。
- 保存失败保留用户输入，显示可操作的错误；简单控件恢复最后确认值。
- 多字段修改整体成功或整体失败，不能无提示地只保存一部分。
- 并发修改发生冲突时重新读取，并允许用户比较和重试，不能覆盖其他端刚保存的设置。
- 无法连接后台服务时，本机界面偏好仍可使用；需要服务读取的配置显示不可用或上次读取值及时间。
- 重启后重新打开页面，读取到的值必须与上次成功保存一致。

### 设置范围与实际值

每个设置项说明范围：当前设备、用户默认、当前项目或当前会话。只有确实支持项目配置的设置才提供范围切换。

智能体配置沿用现有加载规则：内置默认值、用户配置、项目配置、环境变量、启动参数依次覆盖；当前会话可再采用明确的临时选择。设备显示偏好不混进项目配置。不得为展示方便另建一套脱离实际执行的配置合并规则。

页面同时显示可编辑值与当前实际采用值。被环境变量、启动参数或项目配置覆盖时，说明来源；“恢复默认”必须删除该范围的覆盖值，使其重新继承，而不是把当前继承值再写一遍。

项目范围使用明确的项目选择器，不因用户切换背景会话而悄悄改变编辑目标。修改用户默认时，提示当前项目是否仍有覆盖。

### 生效时间

| 生效类别 | 典型内容 | 页面行为 |
| --- | --- | --- |
| 立即生效 | 外观、快捷键、通知、终端显示 | 保存成功后更新当前界面 |
| 下一次模型请求或任务生效 | 自定义指令、默认推理强度、完成后审查 | 不改变已经发出的请求；说明采用时机 |
| 新会话或新终端生效 | 新会话默认批准方式、Shell 和启动参数 | 已有会话或终端保持其启动状态 |
| 重启后台服务后生效 | 默认运行环境、服务级执行设置 | 同时显示保存目标和当前状态，提供受控重启 |

同一个设置只能使用与真实执行流程一致的说明。需要重启后台服务时，不能只重启窗口然后宣称环境已切换。重新打开设置也不能丢失“已保存但尚未生效”的状态。

### 搜索和导航

- 搜索所有实际设置项的名称、说明和常用别名，例如 Shell、WSL、Token、字体、批准、备份。
- 结果显示“页面名称 / 设置项名称”及简短说明，选择后进入对应页面并定位该项。
- 支持方向键选结果、Enter 打开、Esc 清空或退出搜索。
- 空结果提示换关键词，不展示不存在的设置或未实现的入口。
- 搜索索引不包含密钥、环境变量值、个人指令正文或消息内容。
- 返回应用时保留此前项目和会话；页面滚动和焦点符合键盘使用习惯。

### 公共界面和错误处理

使用 [桌面设计基线](../apps/desktop/DESIGN.md)。复用现有组件；需要新组件时按项目约定优先查询 beUI。一个页面保留一个主标题，说明文字明确操作后果，危险操作放在独立区块。

加载、保存中、空数据、读取失败、保存失败、不支持、等待生效均有明确状态。只因依赖缺失而不可用的功能显示原因，不保留可点击但无行为的控件。

所有输入有标签、错误关联及键盘操作。支持深浅主题、缩放、窄窗口和减少动态效果。页面接入后的视觉效果由用户查看反馈，不主动搭建预览或截图流程。

## 权限

本页回答：智能体做什么需要我批准，哪些事情始终被限制，已经批准过的内容在哪里管理。

### 默认批准方式

使用一个选择器，替代“默认权限”“自动审核”“完整访问权限”三个独立开关。

| 选项 | 执行行为 | 默认 |
| --- | --- | --- |
| 手动批准 | 当前工作目录内受信任的只读工具按已有规则运行；编辑、命令和其他需要批准的操作发起确认 | 是 |
| 只读计划 | 保持只读分析，不编辑文件、不执行写入和有副作用的命令 | 否 |
| 自动批准 | 可批准的工具操作自动通过；明确禁止规则、宿主工具上限和文件网络边界仍有效 | 否 |

默认值用于新会话。当前会话继续通过输入框的批准方式切换；页面显示二者的区别。切换到自动批准时确认一次具体后果，不能描述为“敏感操作仍会逐次确认”。

自动批准只省略确认，不解除禁止规则，也不扩大进程访问边界。实现必须调整当前后端提前放行的顺序。只读计划不能被普通允许规则变成可写模式，不能靠选择一个工具别名绕过限制。

### 工具和命令规则

提供规则列表及新增、编辑、删除、恢复继承操作。规则描述对象、动作、作用范围和来源。

- 禁止使用的工具。
- 允许自动通过的工具，仍受禁止规则和宿主能力约束。
- 禁止执行的命令模式。
- 允许或禁止访问的文件路径规则。

编辑器说明匹配方法，并提供不会实际执行工具的“检查规则”操作：输入工具、路径或命令，返回预期允许、禁止或询问，以及命中原因。

明确禁止优先于自动批准。路径规则沿用已存在的匹配语义，界面展示顺序；不能在页面里暗示所有路径规则可以任意重排而不影响结果。允许工具规则不能在界面上演变成不存在的命令自动批准配置。

### 文件和网络边界

这里管理进程实际上能访问哪些位置，而不是只决定是否弹批准框。

- 显示隔离是否启用、当前平台是否支持、是否正在生效、采用哪个限制实现。
- 管理额外允许读写的目录、禁止读取或写入的目录。
- 管理网络模式及允许、禁止访问的域名。
- 显示隔离依赖缺失时停止执行还是继续无隔离运行的实际策略；新增启用时默认选择停止执行，不能默默降低限制。
- 修改前检查目录、当前平台和运行环境是否支持，禁止把未生效的配置展示成已受保护。

SRT 是为本机进程增加文件和网络访问限制的运行工具。现有实现不支持 WSL 与 SRT 的组合；该组合显示不可用原因并阻止启用，不能把 WSL 标签当作隔离成功。未启用隔离时，页面必须明确文件路径审批规则不等于命令进程的系统级限制。

全目录和网络的广泛访问放在高级区域，显示精确作用范围，并确认放宽的权限。自动批准和广泛访问仍是两个独立概念。

### 浏览器和已保存授权

浏览器开发者模式迁移到本页。默认关闭；开启仅允许请求页面结构、控制台和网络诊断，具体检查仍遵循现有单次批准流程。关闭立即停止当前捕获，不只阻止下一次操作。

已保存授权按类别展示：会话工具授权、浏览器站点授权、插件授权。显示授权对象、范围、来源、有效期限或“仅本会话”。不同类别沿用各自真实存储和撤销入口，不伪造统一永久白名单。

撤销后，后续调用重新检查授权；运行中的操作按已有取消能力处理并说明结果。插件权限变更需要回到插件管理页重新审核，不能在此随意编辑其声明。

### 完成验收

- 三种批准方式在新会话里采用正确默认值，已有会话没有被默认值变更影响。
- 禁止的工具、命令和路径在自动批准下仍被拦截。
- 只读计划中的写入、执行和插件副作用请求无法绕过只读限制。
- 规则检查结果与实际权限检查使用同一逻辑。
- 不支持的隔离组合无法启用，依赖缺失按显示策略执行。
- 浏览器模式关闭与授权撤销对后续调用实际生效。

## 终端

本页只配置用户集成终端。智能体命令的执行环境和默认命令 Shell 由运行环境页管理，二者不使用同一个模糊的“默认终端”名称。

### 启动设置

| 设置 | 行为 | 默认和范围 |
| --- | --- | --- |
| 本机默认 Shell | 系统默认或已检测的 PowerShell、cmd、Git Bash 等 | 系统默认，当前设备，新终端生效 |
| 自定义 Shell | 选择可执行文件及分开的参数列表，检查是否可启动 | 未配置，不拼接为未经处理的命令字符串 |
| WSL 终端 Shell | 跟随运行环境页所选发行版的默认 Shell；允许显式覆盖 Linux Shell | 默认跟随发行版，新终端生效 |
| 启动目录 | 跟随当前会话实际工作目录；没有会话时使用所选项目目录 | 默认跟随任务，不采用固定全局项目路径 |
| 终端专用环境变量 | 只覆盖用户终端进程；区分普通值和机密值 | 默认空，不改变系统变量和智能体默认环境 |

已有默认 Shell 偏好迁移后保留。Shell 不存在或已卸载时，显示失效原因与修复操作；不能显示原选择却实际悄悄使用另一个 Shell。

显示当前终端实际 Shell、环境和工作目录的查看入口。运行中的终端不因设置改变而重建或被关闭。

### 显示和交互

- 字体可跟随代码字体或独立选择；独立设置只影响终端。
- 字号范围 10–24 px，默认保留现有 13 px。
- 滚动历史行数范围 1,000–100,000，默认保留现有 5,000 行；说明更高数值占用更多内存。
- 光标形状：块、竖线、下划线；默认块。
- 光标闪烁：默认开启，减少动态效果生效时停止闪烁。
- 多行粘贴确认：默认开启，确认显示行数和内容预览；取消时不向终端写入任何字节。
- 复制、粘贴和终端快捷键提供跳转到快捷键页的入口，沿用终端与应用快捷键冲突处理。
- 主题继续跟随应用，链接打开沿用已有安全处理。

显示偏好保存后更新已有终端。降低历史行数时说明旧历史可能被裁剪；终端滚动历史不等同于持久运行日志。

提供“打开测试终端”，按当前已保存启动设置创建普通用户终端，不自动运行安装脚本或修改项目。

### 完成验收

- 系统检测、自定义 Shell 和失效 Shell 状态都有真实结果。
- 本机和 WSL 分别采用正确的 Shell 与路径格式。
- 新终端读取新启动设置，已有终端进程保持不变。
- 字体、字号、光标和历史设置保存后更新终端并在重启后保留。
- 多行粘贴确认前没有写入，拒绝后没有执行。
- 终端专用变量不影响智能体命令或其他项目。

## Git

本页管理 Git 的长期偏好，并帮助用户确认实际采用的 Git 和提交身份。查看改动、暂存、提交、分支切换、拉取和推送继续在项目 Git 面板完成。

### 检测和提交身份

- 显示 Git 版本、实际可执行文件位置、可用状态和重新检测操作。
- 检查与运行环境一致：WSL 项目不能只检查 Windows 上的 Git。桌面差异读取与智能体 Git 若使用不同环境，分别显示实际来源，不把其中一个检测结果当作两者都可用。
- 显示提交姓名和邮箱，以及来源为当前项目、用户全局、环境覆盖或未配置。
- 允许分别编辑用户全局身份和选定项目身份；默认进入查看状态，保存时明确作用范围。
- 保留其他 Git 配置，不覆盖整个配置文件；输入校验与 Git 命令失败有明确反馈。
- 当前项目不是仓库、Git 不可用或身份缺失时，显示原因和对应处理入口。

凭据由现有系统凭据工具和提供商认证负责。本页不实现新的密码库，也不自动添加全局安全目录信任。

### 差异和分支偏好

- 默认差异范围：全部未提交、仅已暂存、仅未暂存，默认全部未提交。
- 差异显示：统一视图或左右对照；默认沿用现有显示方式。
- 忽略纯空白变化：默认关闭，只影响查看，不改变文件和提交内容。
- 智能体新分支前缀：默认 `vykor/`；用于由 Vykor 新建的分支，不重命名已有分支。
- 分支名与现有分支冲突时生成唯一名称，不覆盖分支。

### 独立工作目录

Git worktree 是同一仓库的另一份工作目录，用来让任务在不同分支上执行而不干扰当前目录。

- 默认任务位置：当前目录或独立工作目录；默认当前目录。会话创建时可以显式选择。
- 独立目录位置：系统管理的任务目录，或用户选择的专用目录。不得位于会被清理的项目内容目录中。
- 管理列表显示所属项目、任务、分支、目录、占用、运行状态及是否有未提交改动。
- 自动清理仅处理由 Vykor 创建、任务已结束、没有未提交内容、成果已合并或用户明确标记可删除的目录；默认关闭自动清理。
- 手动清理先展示目录和内容状态。任务仍在运行、目录无法验证或有未保留成果时，不作为普通清理候选。
- 非 Git 项目不能创建 worktree，返回具体原因；用户明确选择独立目录后失败，不自动回退到当前目录执行写任务。

自动清理不删除用户自己创建的 worktree，不使用强制删除来掩盖未提交改动，也不因任务结束就丢弃分支成果。

### 完成验收

- 检测结果与实际读取差异、执行 Git 的环境一致或明确区分。
- 修改项目身份不改变用户全局身份，修改全局身份不覆盖项目身份。
- 差异偏好只改变显示，默认范围实际用于新开的差异视图。
- 分支前缀用于真实创建过程，冲突不会覆盖已有分支。
- 独立目录创建与任务绑定完整，创建失败不会改变执行目录。
- 未提交内容、未保留成果、活动任务和非 Vykor 目录不会被自动清理。

## 运行环境

本页回答：智能体的文件、命令、脚本和终端在哪里执行，实际采用什么设置，修改后怎样切换。

### 环境选择和实际状态

提供用户默认和明确选定项目的环境设置。项目默认继承用户配置，可独立选择本机或 WSL；默认本机。

WSL 是 Windows 上运行 Linux 工具的环境，只在 Windows 显示。支持选择已安装发行版，默认跟随系统默认发行版；不能使用一份发行版的检查结果宣称另一份可用。

| 显示内容 | 含义 |
| --- | --- |
| 已保存环境 | 下次应用配置时打算采用的环境 |
| 当前实际环境 | 当前服务或任务真正使用的环境 |
| 发行版和 Shell | WSL 实际目标及其默认 Shell |
| 项目路径映射 | 主机项目目录与执行环境中的目录对应关系 |
| 配置来源 | 用户默认、项目覆盖或启动覆盖 |
| 生效状态 | 已生效、待重启、不可用或检查失败 |

项目覆盖和发行版选择需要新增后端能力，必须让文件工具、命令、用户终端、智能体终端和子任务采用同一任务环境绑定，不能只给下拉框增加选项。

当前 WSL 仅支持 Windows 盘符项目映射到 Linux 路径，尚不支持 WSL Linux 文件系统 UNC 项目。页面对不支持的项目位置显示具体原因；新增支持必须同时完成路径、文件、终端和 Git 流程，不能仅解除前端校验。

### 命令环境

- 智能体本机默认命令 Shell：系统默认或已验证可执行文件；与用户终端 Shell 分开存储和说明。
- WSL 命令 Shell 默认跟随所选发行版；覆盖时验证 Linux 可执行文件和参数。
- 用户默认和项目专用环境变量：新增、编辑、删除，并显示覆盖关系。
- 机密变量只显示名称和已配置状态；修改、删除有明确操作，不通过设置快照回传已有明文。
- 查看继承的进程变量时默认只列名称与来源，机密值始终遮盖。不可用变量和非法名称在保存前报错。
- 启动参数使用结构化参数列表，不由界面拼成可能被再次解释的 Shell 命令。

环境变量在下次启动对应进程时生效，不能承诺改变正在运行的进程。项目变量不写入系统全局环境，不混进普通配置导出。

### 检查与切换

“检查环境”验证所选环境可启动、项目目录可访问、Shell 和 Git 可用，并报告 Node.js、Python 等常用工具是否存在。可选开发工具缺失是提示，环境或必要目录不可用是阻止执行的错误。检查只读取必要状态，不安装软件。

切换流程：保存目标，检查目标可用性，显示当前活动任务和终端，用户选择等待任务结束或明确停止并重启，由后台服务安全收尾后重启，重新读取实际环境，成功后清除待生效状态。

不能直接杀掉后台进程制造切换成功。任务停止、终端关闭和重启的后果必须具体说明；切换失败保留已知实际状态，不显示目标已生效。项目环境改变不追溯迁移现有任务。

隔离状态在这里提供摘要和跳转，详细规则仍归权限页。WSL 不等于安全隔离；不重新引入已删除的 Docker 智能体运行环境。

### 完成验收

- 用户默认、项目覆盖和会话启动采用一致的实际环境。
- 多个发行版的检测、路径和 Shell 与选择一致。
- 保存目标、实际状态和待重启状态在重新打开页面后仍准确。
- 活动任务和终端在切换时受到明确处理，不被静默中断。
- 环境变量仅进入对应进程，机密值不进入快照、日志或普通导出。
- 不支持平台、发行版缺失、路径不可映射、检查超时都有准确错误。

## 模型供应商

供应商是提供模型服务的连接。本页统一管理其凭据、模型和默认请求偏好。

- 已连接和可连接供应商、自定义兼容服务及重新检测入口，保留现有来源和显示名称。
- 接入、更新凭据、断开连接、删除自定义服务；操作不影响供应商网站上的账户和订阅。
- 服务地址、模型 ID、显示名称和请求头按真实协议校验。机密请求头与凭据遮盖存储，快照只返回配置状态。
- 区分“已配置”和“已验证可用”。检测本地配置不表示模型请求一定成功。
- 提供连接测试；测试会发送请求或可能计费时，点击前说明。失败区分认证、地址、网络和模型不支持。
- 默认供应商和默认模型：从真实可用模型选择，新会话采用，已有会话保留自己的模型选择。
- 默认推理强度和快速模式：只显示所选模型支持的选项；模型不支持时说明原因，不发送伪造参数。
- 模型能力显示上下文范围及图片输入等已知支持状态；未知能力保留未知，不推断为支持。
- 当前运行禁止修改认证的情况下，说明需要等任务结束或停止后再操作，沿用既有后端限制。
- 删除当前默认连接前明确替代默认模型；无法替代时确认将无法启动新模型任务，不擅自发送到其他供应商。

完成验收：凭据不出现在读取快照和错误日志；默认模型与新会话一致；自定义服务修改和失败有真实结果；已有会话不会静默切模型；能力未知和用量未知不被伪造。

- 启用项目长期记忆、自动提取记忆、会话连续性记忆和记忆整理开关；保留后端现有默认值，展示项目覆盖来源。
- 自动整理的最短间隔和累计会话门槛沿用现有配置，校验为有效正值；整理状态、最近结果和错误读取真实记录。

- 用户手动编辑与后台提取冲突时检查版本，不静默覆盖；无有效记录时显示空状态。

完成验收：指令用于真实请求，项目来源正确；关闭开关后对应行为停止；记忆修改和删除只影响目标条目或项目；没有把临时会话上下文显示为可永久恢复的长期记忆。

## 用量与费用

显示真实模型请求用量。Token 是模型处理文字等输入输出时使用的计量单位；它不等于任务数，也不等于已扣款金额。

### 统计内容

- 时间：今天、最近 7 天、最近 30 天、自定义范围，按应用显示时区确定边界。
- 筛选：项目、供应商、模型；支持汇总与明细，不要求所有项目都在当前侧栏可见。
- 指标：输入 Token、输出 Token、缓存读取和创建 Token、请求数，以及有来源的费用。
- 请求归属：关联真实会话、任务及子任务；同一请求只统计一次，根任务汇总不能再重复相加子任务。
- 重试请求各自计数；失败但已有用量的请求保留用量，供应商没返回的用量记为未知。
- 统计包含完整性说明、已知小计和未知请求数量，历史数据不足以重建时标明范围，不能用消息长度估算冒充账单。

### 费用与导出

供应商返回的费用与根据价格估算的费用分开显示。价格估算附模型、单位价格、币种、来源和采用时间；可以按模型录入估算价格并保留修改历史。没有价格时显示“未提供费用”，不能显示零费用。

价格变化不能重写历史请求的估算依据。订阅型服务显示“费用由订阅承担”或未知，不把其 Token 乘普通 API 价格当作实际扣款。不同币种分别汇总，不采用未配置的汇率合并。

支持按当前筛选导出 CSV 和 JSON，包含时间、项目、供应商、模型、用量、完整性及费用依据，不包含消息、密钥或工具内容。活动图、趋势和常用模型只使用同一真实统计来源；不以示例数据填空。

预算提醒可设置已知费用或 Token 阈值，默认关闭，只提醒不停止任务；统计不完整时说明只能基于已知小计。硬性停止预算不属于本页范围。

完成验收：请求、重试、子任务不会重复计数；未知与零清晰区分；筛选和导出一致；价格和币种依据可追溯；新记录出现后统计刷新；没有虚构订阅余额或 Vykor 支付入口。

## 键盘快捷键

- 按操作名称、所属区域和按键搜索，显示实际注册的快捷键。
- 录入、清除、恢复单项默认和恢复全部默认；Esc 取消录入，不写入未确认组合。
- 冲突检查区分全局、会话、编辑器、终端和浏览器作用域，同一上下文的冲突阻止保存。
- 系统保留按键及平台差异有说明，macOS 和 Windows 不使用错误修饰键提示。
- 保存后实际注册或注销，失败保留最后成功绑定，菜单提示和快捷键页保持一致。
- 文本输入、输入法组合和终端聚焦时，不抢走其正常按键；减少动态效果不影响键盘操作。

完成验收：真实操作触发、冲突拦截、取消、清除、恢复和重启保留均正确；没有只修改显示文字的快捷键设置。

## 连接

本页只管理已有消息渠道。飞书是当前实际接入对象，不列出没有服务实现的平台卡片。

- 连接或重新授权、启用或停用、移除、重新检测；分别显示已配置和实际在线状态。
- 状态包含连接中、已连接、已停用、停止中、连接异常，显示最近更新时间和可处理错误。
- 访问控制管理允许的用户、群聊或其他真实支持的对象，空允许列表保持拒绝全部。
- 被拒绝的消息仅显示必要发送者和会话信息，加入允许列表必须明确对象及范围。
- 消息展示方式与默认目标采用实际渠道能力；命名目标可编辑、测试和删除，不接受任意未授权收件人。
- 测试消息点击前显示接收目标和内容，只有用户明确触发才发送；连接检查不自动给别人发消息。
- 停用停止接收新消息；移除删除本机凭据和授权，说明不会删除平台侧应用或历史会话。
- 渠道凭据不进入模型指令、普通设置快照和导出；外部消息仍遵守智能体批准及访问限制。

完成验收：启停、移除、重连、允许列表和拒绝列表均来自真实服务；空名单不能放行；测试发送只到确认目标；多次平台事件不会重复创建用户任务。

## 存储

本页管理 Vykor 数据，不把用户项目目录当成应用缓存。

### 空间和维护

按类别展示数据位置、占用、统计时间和扫描结果：会话数据库、附件、记忆、运行输出、日志、缓存、插件数据。计算去重及共享文件关系，不把同一文件重复计入总量。

提供打开数据目录、重新扫描和现有附件健康检查。沿用附件扫描、修复与清理入口；修复报告列出处理、跳过、失败项及原因。状态刷新失败时保留上次扫描时间，不能显示维护后最新状态。

清理分开执行：

- 未引用附件：依据真实引用关系，保护活动任务与仍被引用文件。
- 日志和可重新生成缓存：预览候选、时间范围和预计空间。
- 历史任务与会话：选择明确对象或保留策略，展示会被删除的记录和附件影响。
- 插件缓存和数据：通过插件自身维护入口处理；卸载默认保留的用户数据不视为可随意删除的缓存。

默认不自动删除历史会话。保留策略可关闭或设定有效天数，实际清理沿用 [运维与恢复](./operations-and-recovery.md) 的活动记录保护和清理审计。执行前核对实际目录和候选，执行后展示实际回收量及失败项，支持取消尚未开始的批次。

### 备份

选择备份位置和内容，覆盖会话数据库、选定附件与输出、项目记忆及非机密设置。凭据默认排除，恢复后重新连接供应商和渠道。

备份流程：检查目标不在源目录中，说明需要暂停新任务，后台服务停止接收新工作并安全收尾，通过既有备份服务生成文件清单和校验值，返回完成路径及结果，恢复接收任务。活动任务无法收尾时报告原因，不产生标称成功的不一致数据库副本。

用户可以校验已有备份。备份创建记录显示时间、包含内容、大小和完整性，未完成文件不列为有效备份。

### 恢复

先读取清单，校验文件、格式版本和目标目录，展示恢复内容。沿用现有规则，只恢复到空目标目录，不能覆盖正在使用的数据库。

恢复到新的专用数据目录后，提供明确的“切换到恢复数据”操作：暂停和安全关闭当前后台服务，切换其数据位置，启动新服务并重新读取项目和会话。原数据保留；切换失败恢复原数据位置并显示失败原因。该切换入口需要补齐桌面与后台服务能力，不能通过复制到活动目录实现。

恢复不复活旧进程、模型连接或终端；历史活动记录按启动恢复规则处理。格式不兼容、文件损坏或空间不足时拒绝恢复，给出具体原因，不猜测或改写迁移记录。

### 完成验收

- 空间统计分类清楚，不扫描并清理用户源码。
- 清理保护活动及被引用记录，结果有真实审计和失败明细。
- 备份可校验，损坏备份被拒绝，目标不在源目录内。
- 恢复只进入空目录，不覆盖当前数据库，数据切换可回到原位置。
- 恢复后会话和记忆可读取，凭据需重新接入，旧进程不会显示为继续运行。

## 诊断与日志

本页集中解释“为什么不能工作”，不在每个设置页重复一个独立日志系统。

### 状态与检查

- 桌面版本、后台服务版本、实际连接目标、平台、架构及协议是否匹配。
- 后台服务就绪和系统常驻状态，以及活动任务、排队任务、待批准操作数量。
- 当前环境、Shell、Git、模型认证配置状态、MCP 连接摘要、数据目录可写性和剩余空间。
- 最近错误的时间、类别、范围和关联任务入口；网络、认证、环境和数据错误分别说明。
- 检查显示运行中、成功、警告、失败、不支持、取消、超时；某项失败不伪装为整体成功。
- 默认检查只读。模型请求、外部测试消息、安装、修复或重启通过单独明确操作触发。

### 服务和日志操作

- 重新连接后台服务，与重启后台服务分为不同操作。
- 重启前列出活动任务及终端，说明后果并采用安全收尾流程。
- 运行任务故障恢复提供前往现有任务恢复入口的链接，不自动重跑可能有副作用的旧工具。
- 日志按时间、级别、模块和关联任务筛选，支持复制单条和导出当前筛选。
- 默认日志只包含运行标识、状态、耗时和错误分类，不包含模型消息正文、完整工具输入输出或机密。
- 详细诊断开关默认关闭，可设置期限；到期恢复默认，开启也不解除机密遮盖。

### 诊断导出

导出版本、平台、检查结果、非机密配置摘要、有限错误日志及必要运行标识。展示包含哪些分类，默认排除消息、源码、用户指令、机密变量、凭据和未经处理的绝对路径。

默认只保存到用户选择位置，不自动上传或发送。生成失败或某部分不可用时显示缺失项，不能输出看似完整的成功包。问题报告可以引用运行标识，但不能要求用户公开密钥来排障。

完成验收：断连、协议不一致、环境失败、服务未就绪均能准确识别；重新连接和重启行为不同；日志与导出不泄漏机密；检查可取消、有超时；恢复入口不会重复执行旧副作用。

## 状态保存和实现边界

### 数据归属

| 数据 | 保存位置和负责方 |
| --- | --- |
| 主题、通知、快捷键、个人资料、用户终端显示 | 桌面本机偏好，由桌面主进程保存 |
| 工作风格、默认批准、模型默认、记忆开关、审查开关 | 已有用户或项目配置，通过共享设置服务保存 |
| 项目执行环境、环境变量、命令 Shell | 按用户和项目范围由执行服务解析，任务启动时固定采用值 |
| Git 姓名和邮箱 | Git 的项目或用户配置，Git 服务负责读取和修改 |
| 已批准操作、任务、用量、检查结果、清理记录 | 对应后台服务和持久记录，不以页面组件状态充当真相 |
| 模型、渠道和机密变量凭据 | 宿主已有机密存储；新增变量机密存储需明确接口与权限 |
| 非机密设置导出、备份、诊断包 | 用户选定目录，明确清单和格式版本 |

新增配置使用明确格式版本、校验和迁移，不靠读取时猜测字段。已有模型、权限、记忆、终端、Git、备份和日志能力先复用；不在桌面页面里再造一份不同规则的服务。

### 每页实现必须接通的流程

入口在设置页面。界面通过已有桌面进程间调用进入主进程，主进程调用对应后台服务或本机偏好服务，负责方校验并保存，实际使用方读取该值，结果和生效状态返回设置页。

同一后端能力在 CLI、桌面和消息渠道使用时采用同一规则。页面隐藏控件不能代替服务端校验。新接口扩展共享协议时，同步类型、版本、输入校验和调用方；不能只改前端声明。

### 必须一起完成的跨页面关系

- 默认批准方式与会话输入框共用模式含义，禁止规则在各入口一致。
- 运行环境与终端、Git、文件工具、子任务绑定一致。
- 模型供应商的默认模型与用量统计归属一致。
- 终端独立字体与外观代码字体继承关系一致。
- 配置导出、数据备份、诊断导出分别有自己的内容清单，不能混用。
- Git worktree 清理与存储清理互相识别管理对象，保护任务成果。
- 自动记忆、自动审查和后台任务使用正常任务及用量记录，不隐去它们的成本或错误。

## 按页面实施顺序

以下是顺序，不是版本划分。每一项完成该页所有适用需求、执行接线和验收后，再进入下一项。跨页依赖所需的服务能力必须随依赖它的页面一起实现，不能用占位接口记作完成。

1. 权限，包括批准方式、禁止规则、隔离状态、浏览器模式和授权管理。
2. 运行环境，包括用户与项目选择、发行版、命令环境、检查及生效流程。
3. 终端，包括启动、显示、粘贴保护和测试入口。
4. Git，包括实际环境检测、身份、差异偏好和独立工作目录。
5. 诊断与日志，包括环境服务检查、日志和诊断导出。
6. 存储，包括数据分类、维护、清理、备份和恢复切换。
7. 用量与费用，包括真实请求统计、费用依据和导出。
8. 常规，包括控件归位、真实审查开关、配置导入导出。
9. 模型供应商，补齐默认请求设置、连接验证和能力说明。
10. 个性化，补齐记忆管理、来源和生效规则。
11. 通知，补齐事件开关、系统状态、测试和隐私行为。
12. 键盘快捷键，补齐实际作用域冲突和注册反馈。
13. 个人资料暂缓，现有界面和数据保持原样。
14. 外观，核对继承、实际值、回退和动效联动。

搜索、统一保存反馈、生效标签和配置来源是每页接入时同步完成的公共要求。搜索索引随着真实设置项更新，不等全部页面结束才接通。

## 单页完成标准

当前权限页已接入真实批准方式和规则保存、草稿规则检查、实际支持的文件与域名边界、浏览器开发者模式及会话和站点授权撤销。设置冲突在已有文件锁内检查，撤销保留原批准记录。个人资料未改动；后续页面按实施顺序继续。

每页交付必须同时满足以下条件：

- 页面中的设置项、操作和状态都来自真实实现，没有仅摆放的按钮或开关。
- 已完成读取、校验、保存、实际执行、重新读取及重启保留的完整流程。
- 范围、默认值、继承来源及生效时间与真实行为一致。
- 已处理该页适用的加载、空值、错误、不支持、冲突和待生效状态。
- 涉及批准、机密、目录、删除、恢复或进程切换时，按真实路径和后端行为验证边界。
- 自动测试覆盖关键行为和有风险的失败路径；纯样式和简单可逆文案不堆重复测试。
- 运行该页相关测试和必要类型检查；只在跨模块风险需要时扩大检查范围。
- 移除该页原有占位内容，保留应继承的用户设置；数据格式变更有明确迁移。
- 给出实现文件、验证结果和需要用户查看的界面入口，不以样式人工反馈代替行为验证。
