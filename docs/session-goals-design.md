## 1. 产品行为

Goal 是用户显式设置的会话持久目标。服务端保存目标；一轮正常执行后，如果目标仍 active、会话空闲且权限和用户限制允许，就通过现有队列继续推进。用户消息优先。

创建目标后直接执行，使用普通工具与权限。模型按需调查、规划、修改和检查，不先整理正式验收表，也不为每轮额外调用评审模型。

自动续跑默认不限次数（0），Token 预算默认未设置。只有用户明确设置后才限制。已有用量仍记录真实调用及后代运行，失败、中断和迟到报告不会因此丢账。

## 2. 从输入到结果

1. 用户通过现有目标输入模式提交正文；服务端保存目标、正文版本和唯一运行意图。
2. Run 接纳流程检查用户消息、批准、Goal 状态、正文版本及预算后开跑。
3. Goal 扩展注入完整目标与简短续跑规则，提供绑定当前运行的 GoalRead 和 GoalUpdate。
4. 普通回合无需调用 GoalUpdate，正常结束即可继续。模型需要完成、阻塞、明确用户暂停、提问或具体任务等待时才提交控制请求。
5. 控制请求先保存到当前 Run 的 metadata；回合正常结束后，服务端再次核对身份、状态和限制，应用请求或接纳下一轮。失败的回合不能凭先前请求完成目标。
6. 状态和用量通过原通知链更新界面。完成、取消、暂停和真实等待均阻止不应发生的自动续跑。

## 3. 状态、工具与用户控制

状态沿用 active、waiting_user、blocked、paused、completed、cancelled。错误、额度、无效等待等通过停止原因说明，不引入 preparing/executing 阶段。

GoalRead 返回当前完整正文、版本、状态、等待、停止说明及用量。GoalUpdate 只接受以下三类互斥请求，目标身份由宿主绑定：

- 状态：completed、blocked 或用户明确要求的 paused，以及简短说明。
- 问题：需要用户决定的问题正文。
- 等待：具体 targetRunId 和等待期限；宿主核对任务归属并交已有观察器处理。

工具成功只表示请求已记录，模型应正常完成最终回复。普通回合不强制提交报告。用户回答绑定当前问题和正文版本；旧回答、旧批准和旧任务事件不能恢复新版本目标，也不能解除用户暂停或预算停止。

用户可暂停、继续、取消或编辑正文。编辑有明确保存和取消；打开、取消编辑不改变目标。成功保存使旧绑定和等待失效，停止旧运行后再按新版本执行；编辑不自动恢复 paused/blocked 或宿主限制。正文变更不清零累计用量和次数。

## 4. 完成、阻塞与等待的边界

模型完成前对照原始目标，读取当前结果并执行与要求范围匹配的检查。子任务改写文件后，应重新读取文件或重跑受影响检查。Goal 不保存正式条件、证据 ID、文件依赖证明或 Progress Score，也不承诺机器验证任意完成声明。

同一真正阻塞连续至少三个 Goal 回合且已无可行行动时，模型提交 blocked。恢复后重新审查。阻塞是否相同及完成是否可信由模型判断，宿主保存状态并执行身份、权限与限制检查，不做文本相似度评审。

具体任务等待绑定当次 Run，而非代理会话存在。任务完成只接纳一次后续检查；任务失败、等待失效或期限耗尽暂停并说明原因。一次观察超时或读取失败不导致重启任务。

停止操作正常先保存暂停、撤销续跑，再请求中断；暂停保存失败仍尝试中断，并向用户报告暂停未成功，不能把中断成功当成目标已暂停。

## 5. 各层负责什么

| 位置 | 职责 |
| --- | --- |
| Desktop / Client | 目标输入、摘要与正文、适用操作和回答；用量/次数放二级详情 |
| protocol | 请求和状态结构校验 |
| SessionGoalService | 目标状态、控制请求、用户操作及续跑资格 |
| Repository / 事务 | 最小目标、简单正文版本、请求去重、续跑意图和已有用量存取 |
| RunAdmission / RunControl | 用户优先、实际开跑复查、撤销与中断 |
| 等待观察器 | 具体任务归属、真实终态、退避及唯一恢复 |
| Runtime / 模型 | 正常工具执行、目标注入、当前结果检查和完成/阻塞自检 |

普通 Run 不依赖 Goal；不新增执行队列、准备代理、证据平台或预算平台。

## 6. 数据格式与切换

0007_goal_simplification 只丢弃旧 Goal 自有记录，重建最小 Goal、正文版本、模型尝试、请求和续跑五张表，删除旧评估表。会话、输入、消息、Run、工具历史和其他业务数据保留。

不提供旧 Goal 格式转换、回填、双读或自动接管。实际升级前应停止旧服务及其 Goal 工作并备份数据库，再加载一致的新版本。新建目标开始使用收缩后的格式；当前格式内的迟到事件、正文版本及去重保护继续有效。
