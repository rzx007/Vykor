# 工具结果与后续调用

> 状态：当前实现：2026-10-28，采用 [B 方案](./superpowers/specs/2026-10-28-s1-simplification-design.md)。

普通工具合法返回错误表示 completed + isError，保留原输出；下一次调用按当前权限执行。超时、断连或异常影响不明时反馈 unknown，不自动重试，也不扫描历史结果阻止新调用。

Daemon 每次派发检查当前 owner、活跃 Run、输入归属、cwd、工具来源/定义/调用函数与运行修订；普通权限、审批、沙箱和计划模式继续有效。检查不可执行、生命周期投影失败或结果正文保存失败终止当前 Run。

结果仅在完整返回后保存，先保存再截断并发布 result:<UUID>。保存失败不改变 completed 事实，也不发布无效引用。真实工具调用始终登记到结束；迟到结果不审计补写。

S1 三张表、操作状态机、人工核对 API、只读豁免和阻断开关已退役。旧配置键只在文件读取时剔除，在线修改拒绝。旧正文和引用不兼容；升级前备份数据库，回退需同时恢复旧数据库副本与旧程序。具体见 [存储契约](./durable-execution-data-model.md) 与 [运维](./operations-and-recovery.md)。
