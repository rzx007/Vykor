- C1 保存当前正式定义、未冻结/冻结版本及准备请求计数；状态、用量和用户验收不改写定义。

证据读取器只查看已有 Run/消息/Part，不绕过工具权限访问工作区或自行执行命令。普通 Run 没有 Goal 工具或准备 profile；A/B 的版本身份、等待、迟到补账、预算和批准保护继续保留。不对旧数据补值、迁移、回填或删除实际数据库。
