# Goal 证据引用与评估反馈修复

2026-10-15。针对真实会话出现“测试通过，却因引用无效反复重跑并停滞”的问题，沿用现有 Goal 证据链修复。

- Goal 回合的工具结果带真实 `Tool-Result-Id`；该 ID 与持久化 Part ID 一致。普通回合保持原有结果展示，GoalRead 另提供当前 Run 最近的真实引用清单。
- 建议检查命令不再逐字锁死。`commandPolicy: required` 仅用于有来源引用的用户指定命令，仍严格匹配；无效、失败或无关工具结果不因此放行。检查覆盖范围仍由模型解释并逐项审查，不声称宿主能理解任意 Shell 命令的语义。
- GoalAssessment 在写入候选评估前调用宿主只读预检。错误引用、未获支持的“已满足”或进展声明返回具体原因和可用 ID，指示先修正引用而非重跑；普通失败诊断与人工验收保持原路径。
- 预检复用最终读取器，仅当前绑定根 Run 可仍运行；最终结算仍要求终态。两者均检查产物后续修改或删除。多个有效工具结果支持一个进展声明时按来源并集验证。

子代理审核发现并修正了两处边界：运行中根 Run 的产物冲突扫描遗漏，以及多来源进展声明的误拒绝。终审通过。

验证覆盖：核心结果格式 7 项；运行时 Goal 工具与实际模型请求传递 21 项；服务端生命周期、证据、完成策略及进展策略 79 项；协议 13 项，共 120 项。服务端及运行时类型检查通过。额外验证真实宿主记录中只更正引用、不重跑检查、不新增执行轮次即可最终完成。

未修改真实数据库、未自动恢复用户会话、未调用真实模型。运行中的应用需加载新代码后才能使用新反馈。
