范围：只修订文档，保留既有运行保护，删除 Goal 专属准备与通用证据验收。用户要求不兼容旧数据、避免过度设计。本轮未改生产代码、未操作真实数据库、未运行模型任务。

## 集中子代理审核

一名子代理集中检查保留项与删除项、工具入口、状态优先级、等待与编辑、数据切换及能力边界。发现三项必须补齐的设计缺口，已修订：

| 问题 | 最小修订 |
| --- | --- |
| 删除 GoalAssessment 后，提问和具体任务等待没有实际入口 | 同一轻量 GoalUpdate 保留按需提问和登记任务等待；复用现有回答界面、问题身份及等待观察器，不要求每轮调用 |
| 相同 Run 的迟到完成可能覆盖暂停或宿主限制；等待失败没有明确状态 | 事务核对当前状态和停止条件；完成、阻塞、提问和等待只作用于当前可执行绑定。任务失败、等待无效或超时由宿主置 paused 并说明原因 |
| 编辑未规定旧等待如何失效，可能卡住或误恢复暂停目标 | 新正文使旧问题、批准关联、外部观察和续跑意图失效；编辑不解除 paused/blocked 或宿主限制，新版本重新检查执行资格 |

对应规格第 4–6 节及第 10 节验收条目已同步修订；修订不恢复正式条件、证据协议、进展评分或独立评审调用。

## 明确接受的能力边界

- 完成与同一阻塞连续三轮由模型根据当前事实自检；宿主不承诺独立识别所有语义误判或空转。
- 默认不限轮数及 Token 预算；通用运行限制、明确用户控制和可选预算继续有效。
- 不为旧 Goal 数据提供迁移、回填、转换、双读或自动接管；真实数据切换另行限定范围，保留会话、消息、Run 与工具历史。
