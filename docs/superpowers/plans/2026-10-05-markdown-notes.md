# 轻量便签文件存储实现计划

**目标：** 每条便签以独立 `.md` 保存，打开即写、自动保存、搜索找回，不做附件、AI、分类或富文本。

**已确认范围：** 用户于 2026-10-05 批准本地 Markdown 文件方案。界面保持普通文本编辑器，不要求标题、格式或每次选择路径。

**保存目录：** 会话数据库同级的 `notes/`，默认位于用户数据目录的 `data/session-runtime/notes/`。文件以稳定 ID 命名，正文不附加前置元数据，第一行仍由界面派生为标题。

**实现方式：** 正文只从 `.md` 读取和写入；已有 SQLite 仅记录 ID、时间、版本、内容摘要和删除标记，以复用事务和旧写保护。旧 `note` 表及附件表保留作兼容备份，不再作为新正文存储。旧正文首次使用时复制到文件，原记录不删除。
