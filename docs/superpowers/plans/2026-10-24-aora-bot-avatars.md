# aora-bot 头像替换计划

**目标：** 将桌面宠物和新对话起始页的 Blobatar 替换为 aora-bot，保留所有页面操作、窗口行为和布局尺寸。

**实现方式：** 两个页面继续持有随机头像标识。共享 React 组件在浏览器挂载后加载本地引擎，按标识选择形态与配色；标识变化时销毁旧实例，卸载后清理动画和监听。启动遮罩、主进程、IPC、起始页表单均沿用原实现。

**上游版本：** `sam70361/aora-bot` 的 `e3b6148c818da4a8e1966f2bc89cdb3cee473b73`。四份 JavaScript 原样存入共享头像目录的 `upstream/`，保留版权、社区许可、商业许可说明和使用声明。该球形角色禁止商业用途；接入不改变其原有许可。
