# 读取图片工具预览实现计划

**目标：** 已批准的交互为图片读取行按需展开缩略图，点击缩略图打开现有右侧查看器。

**实现流程：** 展开 Read 行后，通过会话、消息、内容 ID 请求主进程读取该工具记录中的图片来源。只接受本机后台已完成且成功的 Read 图片结果；复用图片字节、尺寸和格式检查。界面保留普通参数/结果详情，不将图片字节写入会话摘要。

**技术栈：** React、现有 AttachmentImagePreview / ImageViewerProvider、Electron IPC、Vitest。

- [x] 添加行为测试：折叠时不读取图片，两张图片可分别展开，点击图片打开查看器，失败提示和重试，收起后忽略迟到响应并释放预览 URL。
- [x] 添加主进程测试：成功 Read 图片可预览，非 Read、失败/运行中记录、非图片、过大或无效图片不可预览。
- [x] 实现从工具记录读取图片的主进程函数，连接 IPC / preload / API 类型。入参只传记录 ID，不接受渲染端提供任意路径。
- [x] 实现工具图片预览，复用缩略图和右侧图片查看器；保留其他工具详情。
- [x] 运行相关 Vitest 测试与桌面类型检查，检查 diff。样式由用户运行后查看，不启动预览或截图。

**验证结果：** 图片读取、工具详情、preload 桥接三组测试 66/66 通过。审查发现的旧格式空结果来源选择问题已补失败测试并修正。完整 node/web 类型检查仍有未修改文件中的依赖类型错误；本次修改文件没有报告类型错误。诊断保存在 artifacts/read-image-preview-{node,web}-types.log。

**使用限制：** 仅本机后台已成功读取的图片可预览；文件必须仍存在且满足现有格式/尺寸检查，字节上限为 10 MB。远程后台文件明确提示暂不支持。
