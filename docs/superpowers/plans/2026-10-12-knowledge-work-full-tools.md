# 研究与写作完整工具迁移

用户已确认开始，主要逻辑放在插件内部，控制模块与修改范围。沿用原生工具运行器，不增加数据库、专用 UI、Python 运行环境或通用研究框架。

- [x] 预算与压缩：`tools/budget.mjs`、`compress.mjs` 保留原版问题去重、上限、plan/account、抓取记录累计、原文切片、相关性排序与严格字符预算。纯输入输出，停止建议由智能体执行。
- [x] 学术检索：`tools/academic.mjs` 保留五个固定 HTTPS API、结构化元数据、并发失败隔离和去重。独立声明五个网络主机权限，限制重定向、响应量、超时并响应取消。
- [x] 写作检查：`tools/writing.mjs` 移植证据类别覆盖门槛及稿件词法审校；保留原 decision 与候选问题，不声称验证语义或事实。
- [x] 引用与报告：`tools/citations.mjs` 移植 URL／DOI／原句归属、逐项比较绑定、稳定参考编号、证据与报告 Markdown；保留现有简短调用兼容。
- [x] 实际来源记录：撤回宿主自动落盘、签名、公钥和记录声明。公开稳定的 plugin.dataDir；学术在插件内直接保存来源与逐请求账本，网页通过本轮受限结果读取显式导入插件数据。宿主没有研究专用分支、第二份长期数据或签名体系。旧记录不迁移。
- [x] 组装与说明：更新工具入口、manifest 权限及版本、两个专家、技能、README 和许可说明；准确列明仍由模型负责的语义核对。
- [x] 验证：按风险执行 Node 算法测试、真实 Tool Host、WebFetch 来源记录、权限和取消测试；必要类型检查；真实归档构建与加载；独立审查。避免重复全量测试。

工具契约：预算、压缩、学术、写作工具保留原脚本 snake_case 数据和 `{ok,data}` 结果；调用方用 Read／Write 保存报告及记录，不接受任意脚本路径。学术返回的 text 是摘要，不冒充论文全文。完整引用模式允许 `sources/claims/comparison`，比较中的每个事实字段绑定该候选自己的 claim 与来源；缺口显示未核实。

当前状态：按架构审查建议完成编码与统一针对性检查。66 项插件离线用例、23 项原生运行器用例、19 项执行与反馈用例通过；运行时和 SDK 类型检查、文档检查、1.1.0 ZIP 解压校验与组件加载通过。持久数据与安装快照分离；本轮工具结果读取仅在选中插件的 Run 可用，最多 16 项、单项 256000 字节、总量 1000000 字节，不跨 Run 或重启。插件记录只检测损坏，不是不可篡改的审计证据。未开展全仓库测试、完整桌面安装包构建或真实外网学术 API 验收。

移植范围：保留主要脚本能力并适配原生工具入口，不逐条保留 Orkas 的 CLI 命令与运行环境。预算停止由智能体执行，费用需要真实用量或显式输入；检索摘要不等于论文全文，词法和引用检查不替代语义与事实核对。来源账本反映保留的抓取记录，无法证明记录从未被删除或保存从未失败。
