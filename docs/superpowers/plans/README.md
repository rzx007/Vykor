## 使用流程与状态归属

先读计划的范围和依赖，再按任务修改所属模块，运行对应检查后记录实际结果。复选框和命令输出保存在计划或关联验收记录中；业务状态属于源码及实际数据，不属于本目录。

历史计划按文件名查找；日期和既有勾选不能替代当前版本核实。长期行为完成后写回主题手册，本目录保留过程。

## 新增与维护

新计划使用 `YYYY-MM-DD-<topic>.md`，写明当前状态、文件职责、操作步骤、数据归属、失败处理和验收。相关测试放回被测模块的 `__test__/`，不要放在文档目录中。

新增待实施入口时同步本文件、父级目录和文档总入口；完成后更新实际状态，不从提案文字推断已经实现。文档检查运行 `pnpm check-docs` 和 `pnpm check:retired-ui`。
