# 当前聊天工作摘要聚合实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 当前聊天的应用、工作流和后台终端任务集中到右上角工作摘要，新事项优先提示摘要，点击后沿用右侧面板。

**Architecture:** 摘要读取原应用页面管理器、工作流 Provider 和当前会话的终端状态；不建立第二套执行器或副作用回执。根页面继续拥有应用 iframe；摘要仅展示、提示和导航。

**Tech Stack:** 现有 React、TypeScript、Popover/Button/Item、Zustand、Vitest，复用现有 Main API。

**Spec:** 用户本轮确认的交互：聚合右上角工作摘要、新事项优先展开摘要、手动收起不反复弹开、消息列表保持现状，起始面板去掉应用和编排。

## Global Constraints

- 不提交、不推送，不搭建预览或截图，不新增 UI 依赖。
- 使用现有组件和 DESIGN.md；权限确认与原操作回执流程不变。
- 消息列表内容及具名入口保持；点击入口仍能定位原面板。
- 自动提醒不自动打开或切换右侧面板，不抢编辑焦点。
- 同一事项只自动展开一次；手动收起、普通状态刷新、终端输出、旧历史加载不重复展开。
- 切换会话关闭摘要，隔离工作项和迟到状态响应；已有应用 frame/草稿保持。
- 摘要不读取 iframe 表单，不推断应用未保存状态；仅展示已知宿主状态。
- 右侧空白起始页只移除应用与编排入口，原功能与真正标签仍可使用。
