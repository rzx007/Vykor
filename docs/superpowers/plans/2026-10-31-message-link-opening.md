# 消息链接打开方式

> 状态：已实现并通过相关验证。范围来自本次用户需求；沿用已有桌面偏好、设置 IPC、基础控件和浏览器页签。

## 交互与状态

- 设置提供“每次询问”“Vykor 内置浏览器”“系统默认浏览器”三项。初始为询问，弹窗预选内置浏览器。
- 弹窗显示将要打开的网页地址、“记住我的选择”复选框、取消和打开按钮。未勾选时只处理本次；勾选后保存对应浏览器，以后直接打开。
- 取消不打开、不保存。记忆保存失败时保留弹窗并说明错误。用户可在常规设置改回询问。
- `linkOpeningMode` 属于本机 `desktop-preferences.json`，不写入模型、项目或聊天设置；缺失或无效值回退为询问。
- 消息 HTTP/HTTPS 链接标记后由工作区统一处理，不为每个链接创建状态或读取设置；文件引用继续由现有文件按钮处理。
- 内置打开复用 utility panel 的浏览器页签。异步读取偏好或打开选择期间切换聊天后，取消旧请求，避免在另一个聊天打开。
