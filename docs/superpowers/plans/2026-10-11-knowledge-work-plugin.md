# 研究与写作插件实现范围

用户已确认原生插件方案，并要求避免过度设计、控制修改范围。

目标：在同一个官方插件中提供研究与写作专家，复用现有插件选择、Skill、Agent、Web 和文件工具。成果先保存在工作目录，仅在现有插件页增加添加入口，不增加数据库、插件权限模型或专用工作台。

- [x] `plugins/knowledge-work/`：原生 manifest、两个专家、研究／写作／资料整理技能、使用说明与上游许可说明。
- [x] 一个纯数据工具 `KnowledgeResearchCheck`：核对来源 ID 和原句引用，明确不验证事实真伪或语义支持。不联网、不读写文件、不安装 Python。
- [x] 用现有真实 Tool Host 测试插件加载、技能名称解析、引用错误、输入限制和清理。
- [x] 用最小改动让 Desktop 发行包携带并通过已有安装机制使用插件；不扩大默认对话能力范围。
- [x] 运行受影响测试与必要类型检查，独立审查最终改动。

实施顺序：先定义检查工具测试并观察失败；补插件和工具后验证；再补具体分发入口的回归测试与实现。只处理本任务文件，保留已有文档变更。

第一版边界：网页、文本、Markdown、CSV、JSON；PDF／Office、学术 API 专用工具、图片、成品预览、自动学习和自动跨插件调度均不在本次范围。

验证结果：真实 Tool Host 的 8 项测试、Desktop 四个受影响文件的 49 项测试通过；运行时、插件工具 SDK 和 Desktop Node／Web 类型检查通过。主进程实际构建已生成 `out/bundled-plugins/knowledge-work.zip`，现有归档解析器验证并加载出 2 个专家、3 个技能、1 个工具入口。独立代码审查无必须修复问题。

未修改用户的插件安装记录，未构建完整安装包，也未运行真实模型的研究／写作质量验收。
