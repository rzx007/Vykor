## 目录归属

- `kernel/children/`：子 agent 的管理、登记、环境约定和活动记录；核心查询与事件仍放在 `kernel/`。
- `node/agent/`：Node agent 的构造参数、组装、会话操作和默认工厂。
- `node/children/`：子 agent 配置、本机管理、工作目录和任务等待适配。
- `node/configuration/`：请求配置与模型客户端选择。
- `node/environment/`：默认终端和运行环境接入。
- `node/definitions/`：读取本地 agent 定义。
- `node/tools/`：工具注册、访问范围和每次运行的工具准备。
- `node/memory/`：记忆操作与压缩时补充上下文。
- `node/runtime/`：运行资源、构造器、接入协调和释放资源。
- 其他已有分类保留；测试辅助文件随相关测试移动，共用夹具继续放在 `test-helpers/`。
