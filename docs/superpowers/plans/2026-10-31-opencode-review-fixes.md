## 任务与验证

1. Shell 权限：保留命令原文的词边界，规范化结果只补充拒绝判断；先验证带空格的可执行文件或参数不能借用另一条命令的允许规则，再回归权限包。
2. SSE 心跳：每个未完成事件请求只注册一次完成处理，心跳和取消均释放等待；验证长时间空闲、有事件、拒绝和取消，保留按需读取及溢出关闭。
3. F08 目录别名：发现实际目标的祖先规则，明确别名路径规则的范围与优先级；验证已有和未创建目标、工作区边界、规则权限及修改前阻止。
4. 录制探针：初始化也进入安全错误出口；用合成配置验证设置、凭据和路由异常不会暴露原文或发生网络请求。
5. F08 分类：从实际保留的可信完整规则片段统一计算进展，供失败记忆、纠错额度和轨迹提示使用；保留工具原始失败事实，以及零交付、普通冲突和硬限制保护。

测试先失败再修复。实现文件按问题域分配给不同代理，互不覆盖；完成后由独立代理审查正确性、复杂度和职责。最后运行相关回归、类型检查、文档检查、旧引用检查及差异空白检查。

## 复杂度与职责 Review

独立定向审查、错误传播复核和最终整体审查均无待修复项。规则工具只发现真实祖先并有界读取；受检入口只确认可信宿主事实；引擎确定实际保留的正文并统一分类；恢复和轨迹消费分类结果。进展集合仅活在当前批次，没有规则缓存服务或通用状态机。

事件订阅保管有界队列，HTTP 只保管一个未完成读取和本次心跳等待；错误传播只增加局部捕获与幂等清理，没有第二套队列。Shell 继续识别有限字面语法，录制探针复用现有安全出口。其余 P1/P2 保持原职责及限制；文件锁仍只协调同一 JavaScript 宿主，根 Agent 仍顺序回收，避免增加跨进程锁或并行清理状态机。
