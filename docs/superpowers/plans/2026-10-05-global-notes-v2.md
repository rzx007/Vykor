# 便签二期范围更正记录

日期：2026-10-05

此前把暂存的二期清单全部实施，超出了用户对碎片化记忆的预期。用户随后明确取消 AI 等扩展，并批准每条便签保存为本地 Markdown 文件。

当前执行计划：[轻量便签文件存储](2026-10-05-markdown-notes.md)。当前设计：[轻量便签二期](../specs/2026-10-05-global-notes-v2-design.md)。

本轮仅实现普通文本记录、自动保存、搜索找回及独立 `.md` 文件。不再提供附件管理、富文本、分类、项目关联、系统快捷设置或 AI。

旧数据库正文与已存在数据保留，新的文件目录和索引纳入备份。相关测试及独立审查通过。
