# Server 目录整理实施计划

**目标：** 按职责整理 `packages/server`，测试放在所属分类的 `__test__/`，补齐分类 README，并同步引用和检查清单。

**范围：** 调整文件位置、引用和文档，保留公开入口与既有行为。工作区已有的桌面集成测试迁移等其他改动继续保留。

## 目录归属

- 应用入口保留组装、公共接口与共享支持；业务服务分别归入上下文用量、MCP、项目、插件安装、技能、个性化和配置传输目录。
- 默认服务按配置、模型、扩展、记忆和项目分类；共享配置引用与工厂导出留在上层。
- 会话服务按运行、输入交互、插件、目标、记录投影、维护和运行配置分类；命令、查询、串行操作与公共类型留在会话层。
- 保留 HTTP、守护进程、宿主管理、权限、运行环境等现有分类。HTTP 数据转换归入 mappers。
- 测试随被测模块归类；覆盖多个分类的测试保留在共同上层的 `__test__/`。共用测试夹具继续放在 `test-helpers/`。
