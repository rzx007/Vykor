# 附件保存到工作区实现计划

**目标：** 模型可以将当前会话授权的图片、文档、压缩包及其他附件原样保存到执行环境，随后交给本地工具使用。

**方案：** 新增写入工具 `SaveAttachment({attachment_uri, file_path})`。宿主通过共享附件读取器验证持久引用、文件状态、大小和 SHA-256；文件工具复用现有路径、沙盒、项目说明和修改锁检查，用独占创建发布原始字节，目标存在则拒绝。Host 和 WSL 共用同一工具，只有后端文件操作不同。模型收到保存路径和校验值，不接触附件私有路径或下载令牌。

原生图片和已有文本读取保持原流程；有保存工具时，不能解析的附件作为明确未读取的资源进入上下文。保存不依赖主模型视觉能力、OCR 或图片生成服务，也不会自动执行或解压文件。
