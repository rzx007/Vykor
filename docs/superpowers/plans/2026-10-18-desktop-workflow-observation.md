# 桌面编排观察一期实施计划

> 按用户已确认的交互方案，在当前会话逐项实施；保留工作区原有修改，不提交、发布或修改计划编辑能力。

**Goal:** 聊天摘要、右侧任务图、节点详情和异常定位共享后端真实状态。

**Architecture:** 复用 Jobs 读取与取消、会话事件订阅和右侧工具面板。桌面主进程验证会话归属并读取 Workflow；共享投影解析结构化字段。Renderer 的会话级 Provider 根据 Workflow 事件版本刷新，组件只读取投影。终态与连接状态分别展示。

**Tech Stack:** Electron、React、TypeScript、现有 beUI Tabs/AgentDisclosure、Vitest。

**Spec:** 本会话已确认的一期方案，以及 apps/desktop/DESIGN.md。

## 全局约束

- 复用现有右侧面板及会话范围，不修改其他运行时工作。
- 优先使用已接入 beUI；新组件目录已查阅官方 registry，复用现有适配 Base UI 的 Tabs。
- 图只读、布局稳定，提供步骤列表和键盘操作；不加入暂停或失败续跑按钮。
- 工具返回不代表编排完成；跳过、失败、停止、改动待处理分别表达。
- 不主动启动预览或截图；运行必要的行为测试和类型检查。
