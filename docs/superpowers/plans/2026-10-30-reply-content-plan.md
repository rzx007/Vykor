# 回复内容清单实现计划

**目标：** 在同次生成中先保留事实、限制和未验证项，再组织三种风格；使用新题公平比较改前改后。

**范围：** prompts 包的回复指导、校准示例及说明；不改执行链路，不新增模型阶段，不改变返回协议。

- [x] 冻结8道新题、保留标准、现有回复段及执行链路代码指纹，启动改前真实模型对照。
- [x] 在 `packages/prompts/src/reply-styles.ts` 加共同内容清单，置于风格计划之前；让校准示例先保留内容再示范表达，明确格式和操作限制。
- [x] 更新 prompts 两级 README 与评估说明，明确清单是模型内部表达规则，不能保证零遗漏。
- [x] 运行现有 prompts、runtime 请求配置测试、类型检查、构建及文档/旧引用检查，核查未改执行代码。
- [x] 使用同一真实模型完成改后48个新题样本，独立审查逐项遗漏、事实边界和格式；不按质量重抽。
- [x] 生成包含完整原文的交互报告，报告篇幅差异、重复波动、事实限制覆盖及影响范围。
