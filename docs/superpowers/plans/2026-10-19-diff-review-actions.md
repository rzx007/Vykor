# Diff 审阅交互增强实施计划

**目标：** 完成已确认的四项增强，优先保证选区加入聊天和刷新正确，再补导航与已审阅状态。

**实现方式：** 继续使用 Pierre 的只读 FileDiff、行选区和渲染回调。纯函数负责解析补丁、按旧/新行号提取上下文和导航目标；React 负责请求、视图状态和现有控件组合。复用当前聊天草稿入口，保留原内容及附件。

**约束：** 遵循 apps/desktop/DESIGN.md；复用现有 Button、ButtonGroup、InputGroup、ScrollArea；不增加编辑模式，不预览或截图界面，不提交此前未提交的工作。

1. **选区与上下文**
   - 新建 `review-diff-model.ts` 与 `.test.ts`。`createReviewDiffModel(patch)` 返回解析结果、带旧/新行号的展示行与修改块目标；`reviewSelectionText(model, range, source)` 生成项目、路径、范围、版本侧和关联代码片段，明确处理跨块、跨侧、删除及重命名。
   - 从 `code-selection-actions.ts` 提取 `addTextToComposer(scopeId, text)`，保留聊天身份检查、追加草稿、聚焦和反馈。先验证选区元数据及已有草稿保留，再接入行选区和添加按钮。
2. **刷新当前补丁**
   - 修改 `review-tool.tsx`，每次成功的主动刷新触发当前文件补丁重新读取。请求按项目、范围、空白偏好和文件隔离，旧响应不能覆盖新选择。
   - 同文件刷新期间保留已渲染 diff，移除依赖补丁长度/主题/布局的重挂载 key，保留滚动位置。覆盖同路径同状态刷新、迟到响应及刷新失败测试。
3. **导航与查找**
   - 新建 `review-diff-preview.tsx`，使用 memo 化的 FileDiffMetadata，接入上/下一处修改、文件内查找、自动换行及当前新版行跳转源码。导航定位实际修改行，不定位上下文首行。
   - 复用 ButtonGroup 和 InputGroup；按钮具备 aria-label/title，支持 Ctrl/Cmd+F、Enter/Shift+Enter、Escape 和 Alt+上下方向键。跳转行为尊重减少动态效果偏好，旧版删除行不跳到错误源码行。
4. **已审阅状态与验证**
   - 新建 `reviewed-files.ts` 与测试，以聊天、项目、审阅范围、空白偏好、路径隔离 SHA-256 补丁摘要。内容变化、文件删除和重新出现不继承旧标记。刷新时验证已审阅的非活动文件，限制并发请求数。
   - 文件行使用图标切换状态，摘要显示紧凑计数；加载中的文件不能被错误标记。覆盖同长度补丁变化、项目/范围隔离和非活动文件失效。
   - 按范围运行 Vitest、桌面 Web TypeScript、改动文件 ESLint 和 git diff --check；完成后按代码审查技能独立复核关键请求与选区路径。

**执行：** 在当前会话和工作区顺序实施，每项先运行能证明需求的失败测试，再实现并检查；不增加额外审批。

**完成与验证（2026-10-20）：** 四项已接入。62 项相关测试通过，桌面 Web TypeScript、改动文件 ESLint 与 `git diff --check` 通过。独立复核发现的 gutter API 互斥、暂存区行号误用和迟到校验覆盖新标记均已修正并补上回归测试。依照协作约定未搭建界面预览或截图。

**后续修正与审查（2026-10-20）：** 通过真实 Pierre 组件回归修复保存后的布局对象不一致。提交前审查进一步修正三处问题：使用同目录临时文件完成写入并重新校验源文件后替换，避免中途失败破坏原文；用官方语言映射处理扩展名，未知类型回退纯文本；选区摘录保留新旧两侧缺少末尾换行的标记。均补充了可复现问题的回归测试。
