每项先写能复现问题的测试，确认失败后做最小实现。三个实现任务按不重叠的模块并行；完成后由未参与实现的代理审查，主代理运行相关包与跨包测试。

## F01：复合 Shell 命令权限

- [x] 在 `packages/permissions/src/` 增加保守的字面命令分析；只有能可靠拆开的简单命令才逐条应用既有规则，按拒绝、询问、允许的顺序合并结果。
- [x] 在 `packages/agent-runtime/src/node/runtime/default-runtime.ts` 接入实际执行环境的 Shell 方言；不接受模型输入伪造方言。普通审批模式下，不确定的脚本、替换、重定向和目录切换要求审批；完全访问由统一权限出口应用已选择的授权，明确拒绝、工具范围和计划限制继续优先。不自行实现通用解释器。
- [x] 覆盖分号、换行、管道、逻辑连接、引号、替换、重定向、PowerShell 子表达式和未知方言；验证 `git *` 不能授权后续独立命令，`rm -rf*` 不能被无害前缀掩盖。测试只计算权限，不执行危险命令。

## F05：Read 的实际读取预算

- [x] 在 `packages/tools/src/file/read.ts` 复用 `readBytes` 已有的字节上限及取消信号，限制实际读取，再按行和输出预算截取。大 offset 超过扫描预算时明确说明，不能伪装文件末尾。
- [x] 图片使用独立摄入上限并先检查大小；`info_only` 只有读完文件才提供全文哈希，超限明确拒绝。截断前缀不输出全文摘要证据，不把正常 UTF-8 尾部截断当作非法文件。
- [x] 在 `packages/tools/src/file/__test__/` 断言真实请求和读取字节，覆盖大文件、单长行、图片、offset、无效 UTF-8、取消以及小文件的既有结果。

## F06：事件积压与消费游标

- [x] 在 `packages/server/src/application/events/` 限制每个订阅的实时积压，按固定页重放持久事件；不增加第二套事件存储。超限只结束慢订阅，明确报告最后实际消费的游标。
- [x] 在 `packages/server/src/http/routes/events.ts` 按下游请求读取事件，避免把积压搬到 `ReadableStream`；无读取时也能收到订阅终止信号并清理资源。
- [x] 在 `packages/client/src/state/sync.ts` 分页加载历史和补洞，只有事件成功应用到客户端状态后才推进游标。需要时改进 `packages/services` 的原有事件查询，使限量读取不先复制整个事件集。
- [x] 覆盖不消费的一万条通知、HTTP 不读、快慢订阅隔离、历史分页、取消清理、重连无缺失或重复和临时输出的快照恢复。F07 的范围匹配先保持独立。
