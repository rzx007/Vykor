# 浏览器错误页实现计划

**目标：** 本地文件丢失、HTTP 错误、断网、连接与证书错误、页面进程退出时提供明确反馈和恢复操作。

**实现：** 浏览器工具接收 Electron 的主页面导航与失败事件，把原因保存在当前浏览器实例。错误展示由宿主界面复用现有 Empty 和胶囊按钮；保留底层网页及其地址，重试不跳转到自建错误 URL。HTTP 错误可查看网站原始响应，证书错误没有绕过入口。

## 步骤

- [x] 先为真实 BrowserTool 编写失败回归：文件不存在、HTTP 404/5xx、子框架失败、导航取消、重试与恢复、崩溃。
- [x] 在浏览器分类中增加错误原因模型与错误页，复用项目 UI、语义颜色和响应式换行。
- [x] 接入导航事件；失败后保留错误，新的主页面导航时清理；错误页禁用截图与批注，清理旧 webview 监听。
- [x] 补充错误分类、状态恢复和迟到事件测试，更新本目录 README。
- [x] 执行相关浏览器与文件预览回归、类型和 ESLint、文档与旧 UI 检查，再独立审查。

验证结果：浏览器、文件预览与面板相关测试通过；web 类型、ESLint、文档和旧 UI 检查通过。审查发现的取消导航、非法地址及浏览器尚未就绪时失败等问题均补了先失败再通过的回归测试。

## 边界

- 不把 iframe、图片等子资源失败当成整页失败，不把主动停止或跳转取消当成网络错误。
- 不替换网站地址，不注入网页 HTML，不放宽文件、证书或网络权限。
- 深浅主题使用已有变量，长路径可换行，小面板和低高度可滚动；不启动界面预览或截图。
- 保留当前工作区中并行修改的批注按钮样式及其他功能。
