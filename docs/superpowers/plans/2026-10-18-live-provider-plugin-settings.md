# 运行任务时管理供应商和插件

**目标：** 目录连接显示 models.dev 的最新可选模型；任务运行时允许新增、编辑供应商及刷新、安装插件。

**实现：** 沿用现有接口和运行环境失效机制。当前任务继续使用原配置；后续任务重新创建环境。插件市场刷新只读取列表，不调用重载接口。

**约束：** 自定义模型不被目录覆盖；目录不可用时使用已保存的列表；密钥和请求头保留；卸载、断开连接和禁用的现有限制保留。只修改本需求涉及的代码，不提交其他工作区改动。
