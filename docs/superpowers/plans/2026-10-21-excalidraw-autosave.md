# Excalidraw 自动保存与正式插件移植实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. 用户已确认设计，连续实施并统一定向验证。

**Goal:** 可安装、离线工作的 Excalidraw 插件，支持 Agent 建图、右侧编辑、自动保存、选区协作和导出，保留权限、回执与草稿。

**Architecture:** 沿用 MCP Apps、原工具执行和操作回执。精确工具策略纳入插件定义摘要；安装明确批准自身数据写入，运行时按原身份校验。保存合并未提交编辑，串行提交，收到服务端确认才标记保存；工作区导出逐次确认。

**Tech Stack:** 现有 TypeScript/React/MCP Apps、Excalidraw 0.18.1、SQLite worker、Vitest、真实 Electron 回归。

**Spec:** 用户本轮确认的有限授权、忙时调度、大载荷和 Excalidraw 移植，包含前两轮确定的草稿和权限要求。上游锁定 zai-org/zcode-plugins 的 413f8b688ee9b5bfc763a9cf5dd1fc5913be99cc。

## Global Constraints

- 不提交或推送；不主动截图或搭建样式预览。
- 复用原会话、插件版本/摘要、backend、lease、请求编号与回执；页面不能自授权限。
- 明确拒绝、撤权、角色与只读上限优先；模型不能借用页面自动保存授权。
- 自身数据授权固定数据目录、具体工具和文档身份，不接受任意宿主路径。
- MCP 进程执行插件代码不等同于操作系统文件隔离；准确说明信任边界，不把工具标签当作沙箱证明。
- 普通工具仍限 64 KiB；大载荷按精确工具显式声明、宿主检查，应用请求传输硬上限为 64 MiB。
- 保留上游 LICENSE 与第三方/字体声明；生产包不依赖运行时 CDN。
