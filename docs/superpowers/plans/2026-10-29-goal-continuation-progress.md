# Goal 自动续跑的进展保护

> 状态：已实现并完成本次代码验收。当前行为以 [Goal 手册](../../session-goals-design.md)及源码为准。

**目标：** 阻止正常结束但持续重复结果的 Goal 无限续跑，保留正常写作、工具执行和显式等待。

**设计：** 在 `SessionGoalService.settleRun` 唯一的普通自动续跑入口检查已有运行事实。已确认成功的工具名称、输入、正文和文件变更事实组成本轮结果指纹；调用 ID、结果引用和诊断 metadata 不参与比较。没有工作工具时使用最终交付文字。连续三轮未出现新结果便暂停，复用 `no_progress`。比较对象只保留最近 64 轮的指纹（每轮一个），计数和窗口沿下一次 Run 的 metadata 保存，不新增表、后台任务或模型评审调用。

有工作工具的回合不能通过换一种总结措辞重置计数；工具失败、Goal 状态查询和未提交的模型尝试不算新执行结果。纯文字交付允许新增内容。完成、提问、权限、外部等待和用户额度仍优先按原有规则处理。创建、修改正文、用户消息、手动恢复及外部任务唤醒均重新开始本段判断。

**取舍：** 单纯增加提示词不能强制停止；额外模型评审增加调用、状态和判断不确定性。选择宿主根据已有结果执行一个保守的续跑安全条件，不判断任意任务是否真正完成，也不删除旧聊天记录。
