# 减少重复审批并保护审查资料

> 状态：当前。本次修正已有工具权限和独立审查流程，不修改用户已保存的审批档位。

## 问题与目标

最近两轮渠道可用度检查产生 34 条审批，包含 17 次等待或读取输出，以及 8 次转人工。审批器只收到“好”，没有对应提案及已完成检查的依据；历史输入还可能包含没有敏感标记的裸凭据。

目标是减少不必要的模型审查和人工点击，同时保持明确禁止、工具范围、计划模式、工具来源、会话归属和具体操作确认。

## 处理流程

1. 工具权限先检查禁止规则和范围。受信任内置 `JobList`、`JobRead`、`JobWait` 直接进入宿主的会话归属检查，不再调用审批模型；外部同名工具不能获得此待遇。`JobSend`、`JobCancel` 保持现有权限检查。
2. 需要独立审查的操作继续绑定当前请求、输入、运行和配置版本。用户输入保持先后顺序；补入紧邻该用户回复的助手提案、相关运行已完成的内置工具结果，以及同一运行较早的确切批准记录。这些补充资料全部是参考，不能独立提供用户授权，也不能授权新参数。
3. 附加资料只取本会话、当前及紧邻前轮运行、当前请求之前的记录，使用有界完整片段；无法完整纳入时注明缺失，不拼接一半的资料并假装完整。用户授权与撤销不静默裁剪，保留完整请求长度上限。
4. 独立模型请求发送前统一检查资料。当前指令或本次工具参数含凭据时转人工，不发送请求；历史和参考资料只替换可识别的凭据片段，保留其余限制、顺序和清楚的脱敏标记。无法安全处理、或已有未知敏感内容标记时仍转人工。准备后的固定快照供首次请求与截断重试复用，调用方对象不变。
5. 审查提示区分操作本身的风险、用户授权和资料是否完整。既有登录态用于用户要求的查询不等同于导出凭据；陌生名称或没有系统隔离本身不构成高风险。动态或不明操作仍转人工。
6. Windows PowerShell 工具说明提示宿主已初始化 UTF-8，无需重复生成编码前缀。独立外部检查应有各自请求时限，保留成功结果，只重试失败或未核实部分。等待到期不自动取消任务。

## 状态与边界

没有新增授权缓存或持久化宽泛工具授权；“允许本次”仍只授权当前操作。用户历史和工具结果保存在已有宿主记录中，审查资料为单次临时快照。脱敏不修改原始聊天或凭据配置，不自动执行诊断命令，也不向真实模型重放用户资料。

正则凭据识别是尽力保护，无法可靠识别所有无标签随机字符串；因此保留敏感标记、当前凭据操作转人工、完整资料二次检查和资料大小限制。测试只使用合成凭据。

## 验证

- 真实运行权限测试覆盖可信 Jobs、明确禁止、工具范围、计划模式和外部替身。
- 审查资料测试覆盖短答对应提案、旧批准参考、已完成结果、跨会话/未来/外部/未完成资料排除、缺失说明及配置失效。
- 模型请求边界测试覆盖裸凭据、带标签凭据、历史限制保留、不改变调用方和固定脱敏重试快照。
- 运行相关包测试、类型检查、`pnpm check:retired-ui` 和 `pnpm check-docs`，再进行独立审查。
