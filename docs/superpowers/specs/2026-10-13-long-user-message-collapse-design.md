# 长提问折叠样式优化

## 目标

优化桌面端用户长提问的折叠展示，让正文、底部渐变和“显示更多”操作看起来属于同一个消息表面，并改善 Dark 主题下的渐变可读性。

## 范围

- 只调整 `UserMessageBubble` 的展示样式，不改变折叠阈值、消息内容和展开状态逻辑。
- 保留现有键盘可操作的按钮、`aria-expanded` 状态和“显示更多/收起”文案。
- 浅色和 Dark 主题都使用现有语义颜色变量，不新增固定颜色。

## 设计

- 消息气泡继续作为唯一外层表面，正文和操作区共享同一背景与圆角。
- 折叠时的渐变从透明过渡到消息气泡背景，遮住内容的底部边缘但不产生额外卡片感。
- 操作区取消明显的顶部边框，使用轻微的悬停背景和主题前景色区分交互状态。
- 展开时移除渐变，保留紧凑的操作区；箭头继续表达当前展开状态。
- 动效沿用现有过渡，并通过 `motion-reduce` 保持减少动态效果时的可读性。

## 验证

- 保持现有长消息折叠、展开和收起行为测试通过。
- 检查 Tailwind 类只引用现有语义变量，避免浅色或 Dark 主题出现固定灰色渐变。
