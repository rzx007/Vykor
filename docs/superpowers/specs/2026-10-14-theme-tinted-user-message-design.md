# 用户消息气泡主题浅色设计

## 目标

让主对话和侧边临时对话中的用户消息气泡使用当前主题强调色的浅色调，同时保留正文可读性和现有布局。

## 方案

- 新增独立的 `user-message-bubble` 颜色变量，以 `--primary` 与 `--background` 按 10% / 90% 混合。浅色与深色主题均从当前主题色派生，不固定使用截图里的紫色。
- 用户消息气泡、长消息折叠渐隐和展开栏改用该变量；主对话与侧边临时对话共用同一消息组件，因此样式一致。
- 保持用户消息编辑框及其现有 `user-message` 色值不变。文字颜色、圆角、宽度、间距和操作按钮也不变。
- 更新现有气泡样式断言；不新增组件，不搭建独立 UI 预览。

## 验证

- 运行 transcript 相关测试，确认消息显示断言使用新气泡颜色类。
- 运行 Desktop renderer 类型检查。
- 查看最终差异，确认编辑框仍使用原来的 `bg-user-message/70`，仅展示气泡及其折叠/展开底色改动。
