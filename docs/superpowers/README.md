# 方案、实施计划与验收记录

> 状态：当前过程资料目录入口；各文件按其阶段和证据阅读。

| 目录 | 内容 | 怎样使用 |
| --- | --- | --- |
| `specs/` | 需求、设计和验收标准 | 确认是否待评审、已批准或被替代，不等同于实现 |
| `plans/` | 实施步骤、文件清单和阶段检查 | 用于追踪过程，完成状态仍需代码及验收证据 |
| `reviews/` | 一次评审或验证的发现和结果 | 只适用于所检查版本及范围，不保证后续实现未变 |

文件名日期帮助定位，不能单独证明新文件已经实施。旧方案与当前代码冲突时，按[文档维护约定](../documentation-policy.md)核实；确定已经替代的方案保留历史，当前规则写回主题手册。

当前入口和已知待评审提案见[文档目录](../README.md)。新增过程记录沿用对应子目录，不把长期操作手册放在实施计划中。
