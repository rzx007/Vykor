# Desktop 电脑操作

> 状态：当前实现，Windows x64 试点。阶段 5 已完成实机验收，签名安装包与真实模型的结果见接入计划。

Windows x64 Desktop 启用此功能后，在主聊天直接描述任务，例如「打开计算器，算一下 7 × 8，给我看看结果」。模型按任务决定是否调用电脑操作。应用需要授权时，当前对话会显示批准卡。Vykor 查找 Windows 已登记的应用，再启动或复用窗口。多个匹配窗口由你选择。切换或隐藏主聊天后，旧任务的电脑操作许可失效。

可直接在消息里写明目标应用。已保存的应用许可可在「运行设置」撤销。只想发图时，用「添加上下文」选择「分享窗口截图」，在本机菜单选一个可用窗口，再看附件预览并自行发送。

Windows x64 安装包包含固定版本的控制驱动。已打包的 Vykor 默认关闭电脑操作。试点时以 `VYKOR_COMPUTER_USE=1` 启动，驱动资源完整时即可使用。以 `VYKOR_COMPUTER_USE=0` 启动可以停用。Windows x64 的开发启动会自动准备驱动，就绪后默认启用。 [开发驱动准备](../apps/desktop/resources/computer-windows/README.md)

## 已验证范围

- **应用和窗口**。计算器、画图和测试窗口走 Windows 登记入口，桌面快捷方式保留登记参数。记事本的已有文档可按标题复用，再读回多行编辑结果。多个窗口符合时由你选择。明确请求新窗口时，Vykor 会尝试启动并等候一个独立窗口。部分应用会复用原窗口或打开标签页，这时会报告未能确认新窗口。 [应用发现实机](../tests/desktop-integration/__test__/computer-windows-live.test.ts) · [记事本实机](../tests/desktop-integration/__test__/computer-windows-semantic-live.test.ts)
- **控件和读回**。应用公开的按钮、编辑框、选择和滚动可按控件身份操作。写入或选择可按返回值核对，按钮根据界面变化报告结果。确认保存需重新打开文件，或读取获准的位置。 [操作方式](../apps/desktop/src/main/features/computer/README.md)
- **截图与前台输入**。助手可把核对结果的窗口截图附在最终回答下方。操作中临时预览限于当前聊天。前台许可覆盖按键、输入文字和点击，坐标需要最新画面。计算器和 WinForms 通过实机验证。自绘控件、依赖系统硬件键态的快捷键及 Windows 安全对话框可能需要人工操作。 [前台实机](../tests/desktop-integration/__test__/computer-windows-foreground-live.test.ts)

## 遇到问题时

- 找不到应用时，核对开始菜单名称。多个窗口符合时，在候选列表选择。目标不明时任务等候复核。
- 应用授权后，操作遵循当前聊天的授权模式。完全访问直接执行，请我批准时用聊天卡片，自动审查沿用现有审查流程。密码及系统安全界面由用户处理。暂停后可手动接管，继续时重新核对和观察窗口。
- 模型按任务决定是否使用前台键鼠。前台接管期间会显示屏幕泛光和顶部 Esc 提示。窗口预览、暂停和继续可从输入框的电脑操作选项查看。
- 前台控制时按 Esc，或在聊天中点「停止」，都会撤销本轮授权。工具记录会显示「未执行」「已确认」或「待核对」。待核对时先观察目标窗口，检查实际结果。任务已经结束时可新发一条消息，只核对结果。
- 同一任务可以接着用内置 Browser。切换前 Vykor 等待 Windows 键鼠释放，浏览器的网站访问继续按浏览器权限处理。需要回到 Windows 点按时重新观察并取得前台许可。
- 截图可在聊天关闭。已发出的截图无法撤回，模型重试只使用文字。 [图片边界](../packages/server/src/application/computer-tools/README.md)
- 缺少驱动时入口不可用。运行中校验不通过时，重新安装已核验的安装包。升级、重启或切换数据目录后需要重新授予任务许可。 [安装包核验](../apps/desktop/docs/packaging.md)
