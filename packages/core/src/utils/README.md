# 共用工具函数

存放可被多个 core 模块使用、不需要保存会话状态的辅助函数。

| 文件 | 用途 |
| --- | --- |
| `message-history.ts` | 清理消息历史，识别工具调用与结果，检查分割位置是否破坏配对 |
| `token-counter.ts` | 按文本长度粗略估算 token 数，供容量统计和压缩参考 |
| `retry.ts` | 通用异步操作重试，处理退避等待、可重试状态和服务端等待建议 |
| `__test__/` | 消息历史处理测试 |

查询引擎与压缩模块调用消息历史函数，拿到处理后的结果，再由各自的入口更新状态。这里不持有消息或注册表。

新增函数应有明确的共用用途。模型请求专用的重试规则放在 `../engine/model/`；只被单个分类使用的处理逻辑留在该分类。测试与实现同层，放入 `__test__/`。
