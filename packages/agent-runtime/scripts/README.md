# 构建与发布验证

| 文件 | 用途 |
| --- | --- |
| `build.mjs` | 打包默认入口、执行核心和工作流入口，复制插件子进程入口 |
| `kernel-boundary.mjs` | 检查执行核心的打包依赖和类型声明，防止引入本机宿主能力 |
| `verify-pack.mjs` | 打包并在独立消费者中验证公开入口、类型和运行行为 |
| `__test__/` | 依赖检查脚本的正反例测试 |

`pnpm --filter @vykor/agent-runtime build` 先生成声明，再运行打包脚本。`test:pack` 在构建后验证实际发布内容，临时消费者与安装结果由脚本管理。

新增构建或发布检查放在本目录，脚本测试放在同层 `__test__/`，并同步 `package.json` 中的命令。执行核心目录迁移后，需要同时验证构建依赖图和声明引用链。
