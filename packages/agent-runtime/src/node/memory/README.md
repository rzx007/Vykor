# 记忆与补充上下文

| 文件 | 用途 |
| --- | --- |
| `memory-runtime.ts` | 创建记忆运行能力，处理检索、提取和受运行上下文约束的记忆操作 |
| `remember-tool.ts` | 将记忆操作包装为可注册的工具 |
| `compact-context.ts` | 从调用方读取会话记忆和补充章节，供历史压缩使用 |
| `__test__/` | 记忆归属、工具行为和压缩上下文测试 |

组装层创建记忆能力并注入 agent。运行中通过受约束的记忆入口处理请求，压缩时由上下文提供函数读取最新补充内容，再交给 core 的压缩服务。

本层保留服务引用和执行上下文，记忆数据由 `@vykor/memory` 等提供方保存；压缩后的历史仍由查询引擎持有。新增记忆接入与上下文收集放在这里，摘要和消息压缩算法放在 core。测试放在同层 `__test__/`。
