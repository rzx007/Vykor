# 请求配置与模型客户端

| 文件 | 用途 |
| --- | --- |
| `request-configuration.ts` | 带版本的请求配置存储、校验和更新通知 |
| `default-runtime-provider.ts` | 根据模型与提供方配置选择模型名、凭据和 API 客户端 |
| `__test__/` | 配置更新和客户端选择测试 |

调用方先提供本机设置和可覆盖的请求配置，运行组装层用它们选择客户端。请求开始时读取配置快照，确保同一次请求使用一致的模型和限制。

内存配置与版本保存在 `MemoryRequestConfigurationStore` 实例中；设置和凭据的持久化由相应配置、认证包管理。新增模型选择或请求配置规则放在这里，具体模型协议实现放在 `@vykor/api`。测试放在同层 `__test__/`。
