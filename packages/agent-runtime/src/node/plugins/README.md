# 插件发现与运行能力

负责发现已安装插件、选择有效安装、启用插件能力，并为每次运行固定允许的插件、工具、技能和定义。

| 文件或目录 | 用途 |
| --- | --- |
| `plugin-discovery.ts` | 发现插件并返回扩展与能力目录 |
| `extensions.ts` | 配置扩展，按来源注册工具 |
| `plugin-capability-inventory.ts` | 选择安装版本，归集工具和连接的原始所有者 |
| `plugin-activation.ts` | 启用已发现插件的能力 |
| `plugin-selection.ts` | 插件选择候选、目录和结果类型 |
| `plugin-discovery-context.ts` | 生成供模型选择插件使用的提示上下文 |
| `run-capability-view.ts` | 创建和收紧本次运行固定的能力范围 |
| [native-tools/](./native-tools/README.md) | 本地插件工具进程与调用保护 |
| `__test__/` | 发现、版本选择、能力归属、停用、升级和子运行继承测试 |

组装时发现并启用能力，提交时从当前有效安装中捕获运行视图。后续授权、工具调用和子运行依据该视图检查来源；插件停用或升级时也要核对原始身份。

安装状态由插件包管理，本层的目录和运行视图保存当前进程捕获的能力。新增发现与运行范围规则放在这里，应用页面调用放在 `../plugin-apps/`。测试放在同层 `__test__/`。
