# 本地插件工具进程

在独立的 Node 进程中加载插件工具，处理注册、调用、取消和日志，再将结果返回运行宿主。

| 文件 | 用途 |
| --- | --- |
| `activate.ts` | 启用插件工具，向运行注册表提交结果 |
| `tool-host.ts` | `NativeToolHost`，启动子进程并管理请求、超时和关闭 |
| `host-entry.mjs` | 子进程入口，加载插件模块并执行工具 |
| `protocol.ts` | 宿主与子进程间的注册、调用、取消和日志消息约定 |
| `guard.ts` | 调用保护、参数与资源限制，以及审计事件 |
| `status.ts` | 记录和读取本地工具运行状态 |
| `__test__/` | 宿主协议、插件数据、实际插件和插件开发流程测试 |

启用时创建宿主并捕获注册结果，调用时先通过保护检查，再把请求交给子进程，收到结果后按请求编号返回。进程和待处理请求由宿主持有，插件持久数据由授权的数据目录保存。

`tool-host.ts` 与 `host-entry.mjs` 保持相邻，构建时将进程入口复制到发布目录。迁移本目录时需要同时检查构建脚本和桌面打包引用。新增进程协议或保护规则放在这里，测试放在同层 `__test__/`。

官方插件由 `vykor-plugins` 仓库独立测试和发布。需要用真实“研究与写作”插件检查宿主兼容性时，设置测试变量 `VYKOR_OFFICIAL_PLUGINS_DIR` 指向其 `plugins` 目录，再运行 `__test__/knowledge-work.test.ts`。未设置时仅跳过这一组外部插件测试；正常宿主检查不读取相邻仓库，也不保留官方实现副本。
