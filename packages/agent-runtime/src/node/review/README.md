# 权限审查接入

`approval-reviewer.ts` 定义权限审查器，处理审查请求、结果解析和失败时的后备结果。`approval-secrets.ts` 在发送前检查并整理凭据片段；`configured-approval-reviewer.ts` 根据用户配置选择模型客户端，创建实际使用的审查器。

调用方传入待审查操作，审查器通过受限的辅助请求获得判断，再返回约定格式的结果。解析或调用失败时按已有规则返回后备判断。

审查同时读取宿主核实的本轮用户输入和按先后排列的人类历史输入，结合前文理解“好”等短答；后来的限制或撤销覆盖更早授权。工具描述、输出及其他参考资料不能充当授权。返回的理由使用简短中文，供界面直接说明为什么需要人工确认。

本轮用户指令或实际工具与参数包含凭据时，在发起独立模型请求前转为人工确认。历史用户指令及 `reference` / `tool_output` 正文中的凭据只替换相应片段为 `[已移除凭据]`，保留其余文字、禁止条件及顺序；过去粘贴的旧密钥不会阻断后续无关的状态检查。JSON 参考中的带引号字段值同样处理，实际工具参数中的敏感字段仍整次阻断。准备过程复制调用方资料，完成脱敏后再检查全量内容；不能确定凭据边界，例如未闭合的私钥块或存在歧义的引号时，转为人工确认，不截断或整条丢弃历史。宿主的敏感输入标记仍由服务器先行整次阻断。

识别范围包括常见密钥前缀（如 `gsk_`、`sk-`、GitHub token）、Bearer / Basic、私钥块、JWT、含用户名密码的网址，以及明确标记的密码、密钥、token、cookie 等赋值。带厂商前缀的完整环境变量名也参与检查，例如 `.env` 中的 `GROQ_API_KEY=...`、JSON 字段 `OPENAI_API_KEY` 和 PowerShell 的 `$env:AWS_SECRET_ACCESS_KEY = ...`；只有变量名引用、没有赋值值时不当作原文凭据。中英文标签支持全半角冒号及等号。普通 SHA256、UUID 和路径不按高熵程度猜测为凭据；没有已知格式或上下文标记的任意字符串无法可靠区分。模型返回的理由若出现可识别凭据，也使用固定提示转为人工确认，不向界面回显该值。

审查请求预留 4096 token，供模型思考和输出最终判断；仅在服务商明确报告输出截断时，使用相同的固定资料重试一次，上限增至 8192 token。两次请求共用 30 秒总时限，取消后不再重试；不拼接残缺输出，也不根据残缺的批准结果放行。拒绝、无效格式、工具调用或连接失败不触发这项重试。

配置和客户端保存在审查器闭包中，实际批准与执行仍由调用方的权限流程负责。新增审查提示、解析或配置接入放在本目录；具体模型协议实现放在 `@vykor/api`。测试放在同层 `__test__/`。
