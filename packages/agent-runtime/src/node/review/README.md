# 权限审查接入

`approval-reviewer.ts` 定义权限审查器，处理审查请求、结果解析、敏感信息和失败时的后备结果。`configured-approval-reviewer.ts` 根据用户配置选择模型客户端，创建实际使用的审查器。

调用方传入待审查操作，审查器通过受限的辅助请求获得判断，再返回约定格式的结果。解析或调用失败时按已有规则返回后备判断。

审查请求预留 4096 token，供模型思考和输出最终判断；仅在服务商明确报告输出截断时，使用相同的固定资料重试一次，上限增至 8192 token。两次请求共用 30 秒总时限，取消后不再重试；不拼接残缺输出，也不根据残缺的批准结果放行。拒绝、无效格式、工具调用或连接失败不触发这项重试。

配置和客户端保存在审查器闭包中，实际批准与执行仍由调用方的权限流程负责。新增审查提示、解析或配置接入放在本目录；具体模型协议实现放在 `@vykor/api`。测试放在同层 `__test__/`。
