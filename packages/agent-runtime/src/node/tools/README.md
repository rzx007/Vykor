# 工具接入与运行准备

| 文件 | 用途 |
| --- | --- |
| `default-tool-registry.ts` | 调用工具工厂，组装默认工具注册表 |
| `tool-ports.ts` | 将技能、配置、MCP 和飞书能力适配为工具需要的接口 |
| `default-runtime-tools.ts` | 应用工具配置，生成模型可见、应用调用和委派使用的工具范围 |
| `prepare-run-tools.ts` | 根据本次能力快照重新绑定工具，登记本次运行可用的定义 |
| `__test__/` | 注册表、工具范围、权限结构、MCP 授权与运行视图测试 |

运行组装时建立基础注册表；提交时再依据当前允许的技能、插件和 MCP 来源准备本次工具。返回的绑定交给执行核心和查询引擎使用，后续配置变化通过下一次准备生效。

重新绑定子运行工具时，保留本轮的 `toolSafety`（工具操作记录与强制检查），包括只通过 preparation 提供安全能力的 SDK 调用；未提供时仍沿用原行为。

基础工具保存在运行资源的注册表中，本次能力由运行目录记录。新增本机工具适配和准备规则放在这里，具体工具实现放在 `@vykor/tools`，通用执行检查放在 `@vykor/core`。测试放在同层 `__test__/`。
