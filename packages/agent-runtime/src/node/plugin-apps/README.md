# 插件应用执行

将插件应用页面的工具请求交给原始已授权后端执行，并把实际工具结果转换为应用结果。

| 文件 | 用途 |
| --- | --- |
| `plugin-app-backends.ts` | 后端接口、目录和工具绑定捕获 |
| `native-plugin-app-backend.ts` | 捕获本地插件工具后端与资源，并转换执行结果 |
| `mcp-plugin-app-backend.ts` | 捕获 MCP 工具后端并转换结果 |
| `plugin-app-runtime.ts` | 应用调用入口，核对原始来源、权限、限制和结果交付 |
| `policy.ts` | 计算应用工具的有效权限与资源限制 |
| `__test__/` | 应用策略、原始绑定、后端执行和调用链测试 |

插件接入时捕获原始后端，页面发起操作后，本层先核对本次运行、插件和工具归属，再请求授权并调用原始绑定。结果沿同一条调用链返回页面。

后端绑定与资源快照由目录和运行实例持有，实际工具和连接由提供方管理。新增应用调用与结果转换规则放在这里，插件发现和本地工具进程放在 `../plugins/`。测试放在同层 `__test__/`。
