# 共用测试夹具

| 文件 | 用途 |
| --- | --- |
| `plugin-app-fixture.ts` | 创建可实际调用的插件应用安装与测试配置 |
| `notes-app-fixture.ts` | 准备便签插件应用的测试安装 |
| `native-plugin-authoring.ts` | 在临时目录验证插件开发、构建和工具执行 |
| `native-tool-logs.ts` | 收集和检查本地插件工具日志 |

这些辅助代码由包内和其他包的测试共用，调用时创建夹具或返回辅助数据，资源清理由夹具约定与调用方负责。本目录不参与公开 API 导出。

只放需要跨分类或跨包复用的夹具。单个分类专用的辅助代码随测试放在对应 `__test__/`。迁移共用夹具时同步所有测试引用，并核对 Turbo 测试缓存的输入路径。
