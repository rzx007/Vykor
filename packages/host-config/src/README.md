# 本机配置源码导航

提供用户与项目配置的类型、读取、校验和保存入口。

## 主要文件

| 文件 | 主要导出 |
| --- | --- |
| [index.ts](./index.ts) | 统一导出本分类的类型与函数 |

## 分类目录

| 目录 | 用途 |
| --- | --- |
| [extensions/](./extensions/README.md) | 定义 Hook、MCP 连接配置和凭据记录格式。 |
| [permissions/](./permissions/README.md) | 定义审批模式并整理权限设置。 |
| [settings/](./settings/README.md) | 管理设置类型、合并规则、受控修改以及工具和调度配置。 |
| [storage/](./storage/README.md) | 确定配置与 Git 路径，并提供配置文件的原子写入。 |

## 入口与处理步骤

主要入口或定义见 [index.ts](./index.ts)。

先确定配置目录，读取并合并用户与项目设置，再校验字段；修改时通过现有锁和原子写入流程保存。

## 状态放在哪里

配置文件保存在用户或项目配置目录；读取结果和单次修改上下文由调用方持有。

## 新代码与测试

根目录保留包入口和分类导航；具体实现放入对应分类。

新增测试放在本目录的 `__test__/`；跨分类用例放在共同目录的 `__test__/`。
