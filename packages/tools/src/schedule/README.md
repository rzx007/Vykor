# 调度工具

向宿主提交计划任务的读取与修改操作。

## 主要文件

| 文件 | 主要导出 |
| --- | --- |
| [index.ts](./index.ts) | 统一导出本分类的类型与函数 |
| [scheduled-task-tools.ts](./scheduled-task-tools.ts) | `createScheduleTools` |

## 入口与处理步骤

主要入口或定义见 [index.ts](./index.ts)。

解析调度输入，通过调度接口请求操作，再把保存结果或当前计划返回给模型。

## 状态放在哪里

单次调用保存输入、取消信号和执行结果；文件、进程及任务状态由注入的宿主接口或目标系统保存。

## 新代码与测试

与本目录职责一起修改的代码放在这里；跨分类的公共入口由上层目录组织。

测试位于 [`__test__/`](./__test__)；只覆盖下级分类的测试放在对应分类的 `__test__/`。
