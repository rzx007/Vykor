# 工具通用取消处理

复用工具执行时的取消信号处理。

## 主要文件

| 文件 | 主要导出 |
| --- | --- |
| [abort.ts](./abort.ts) | `createToolAbortScope` |

## 入口与处理步骤

主要入口或定义见 [abort.ts](./abort.ts)。

工具把当前取消信号交给共用函数，执行前或等待期间检查取消情况，再按现有错误流程结束调用。

## 状态放在哪里

单次调用保存输入、取消信号和执行结果；文件、进程及任务状态由注入的宿主接口或目标系统保存。

## 新代码与测试

与本目录职责一起修改的代码放在这里；跨分类的公共入口由上层目录组织。

测试位于 [`__test__/`](./__test__)；只覆盖下级分类的测试放在对应分类的 `__test__/`。
