## 分类目录

| 目录 | 用途 |
| --- | --- |
| [workflow/](./workflow/README.md) | 把工具调用转换为工作流运行请求。 |

## 入口与处理步骤

主要入口或定义见 [index.ts](./index.ts)。

工具解析模型输入，经宿主接口提交 Agent 或团队操作，再把状态与结果返回给模型。

创建子 Agent 时，目录取可信执行环境的宿主根目录；环境内执行路径继续留给工具和进程使用，不能作为宿主会话目录保存。

## 状态放在哪里

单次调用保存输入、取消信号和执行结果；文件、进程及任务状态由注入的宿主接口或目标系统保存。

## 新代码与测试

与本目录职责一起修改的代码放在这里；跨分类的公共入口由上层目录组织。

测试位于 [`__test__/`](./__test__)；只覆盖下级分类的测试放在对应分类的 `__test__/`。

模型侧 Agent 参数不提供 `maxTurns`，不把模型自选的数字传成子运行的硬上限。轮数预算由角色、宿主配置或宿主直接调用指定，仍由 Runtime 和 Core 统一执行；显式上限的最后一轮预留给无工具总结。没有配置轮数上限时，不额外添加默认上限。
