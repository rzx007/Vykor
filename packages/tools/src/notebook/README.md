# Notebook 工具

读取或修改 Notebook 文档中的单元格。

## 主要文件

| 文件 | 主要导出 |
| --- | --- |
| [index.ts](./index.ts) | 统一导出本分类的类型与函数 |
| [notebook-tool.ts](./notebook-tool.ts) | `notebookEditTool` |

## 入口与处理步骤

主要入口或定义见 [index.ts](./index.ts)。

解析 Notebook 路径与目标单元格，调用文件能力处理内容，再返回文档修改结果。

## 状态放在哪里

单次调用保存输入、取消信号和执行结果；文件、进程及任务状态由注入的宿主接口或目标系统保存。

## 新代码与测试

与本目录职责一起修改的代码放在这里；跨分类的公共入口由上层目录组织。

新增测试放在本目录的 `__test__/`；跨分类用例放在共同目录的 `__test__/`。
