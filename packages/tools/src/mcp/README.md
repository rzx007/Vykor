# MCP 工具适配

把已连接 MCP 能力包装成模型可调用的工具。

## 主要文件

| 文件 | 主要导出 |
| --- | --- |
| [index.ts](./index.ts) | 统一导出本分类的类型与函数 |
| [mcp-tools.ts](./mcp-tools.ts) | `createMcpTools` |

## 入口与处理步骤

主要入口或定义见 [index.ts](./index.ts)。

从宿主取得 MCP 工具描述，建立工具定义，执行时转交 MCP 接口并整理结果。

`McpToolCall` 只接受已加载的 MCP 来源工具。尚未加载或不存在的目标交给宿主拒绝；当前 Run 中搜索加载目标后，可重新调用并重新检查普通权限。同名的非 MCP 工具和缺少注册表的调用仍拒绝。

## 状态放在哪里

单次调用保存输入、取消信号和执行结果；文件、进程及任务状态由注入的宿主接口或目标系统保存。

## 新代码与测试

与本目录职责一起修改的代码放在这里；跨分类的公共入口由上层目录组织。

测试位于 [`__test__/`](./__test__)；只覆盖下级分类的测试放在对应分类的 `__test__/`。
