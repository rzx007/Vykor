# 笔记与记忆

定义跨端共享的笔记和记忆数据。

## 主要文件

| 文件 | 主要导出 |
| --- | --- |
| [memory.ts](./memory.ts) | 统一导出本分类的类型与函数 |
| [notes.ts](./notes.ts) | `parseCreateNoteInput`、`parseUpdateNoteInput` |

## 入口与处理步骤

主要入口或定义见 [memory.ts](./memory.ts)。

服务端读取笔记或记忆后构造公共数据；客户端使用这些字段展示和提交修改。

## 状态放在哪里

这里只定义和校验传输数据；业务数据由 Services 保存，客户端展示状态由 Client 保存。

## 新代码与测试

与本目录职责一起修改的代码放在这里；跨分类的公共入口由上层目录组织。

测试位于 [`__test__/`](./__test__)；只覆盖下级分类的测试放在对应分类的 `__test__/`。
