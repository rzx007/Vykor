# 审批与自动审查

定义审批模式、审批结果及自动审查信息。

## 主要文件

| 文件 | 主要导出 |
| --- | --- |
| [approval-mode.ts](./approval-mode.ts) | 统一导出本分类的类型与函数 |
| [approval-review.ts](./approval-review.ts) | 统一导出本分类的类型与函数 |
| [auto-review.ts](./auto-review.ts) | 统一导出本分类的类型与函数 |

## 入口与处理步骤

主要入口或定义见 [approval-mode.ts](./approval-mode.ts)。

配置或控制请求传入审批字段，校验后由服务端审批流程处理，结果再以这里的公共格式返回。

## 状态放在哪里

这里只定义和校验传输数据；业务数据由 Services 保存，客户端展示状态由 Client 保存。

## 新代码与测试

与本目录职责一起修改的代码放在这里；跨分类的公共入口由上层目录组织。

测试位于 [`__test__/`](./__test__)；只覆盖下级分类的测试放在对应分类的 `__test__/`。
