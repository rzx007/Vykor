# 插件来源源码导航

从 Git、本地 ZIP 或插件市场定位并取得可供安装的插件目录。

## 主要文件

| 文件 | 主要导出 |
| --- | --- |
| [index.ts](./index.ts) | 统一导出本分类的类型与函数 |

## 分类目录

| 目录 | 用途 |
| --- | --- |
| [marketplace/](./marketplace/README.md) | 解析市场条目并取得对应插件归档。 |
| [sources/](./sources/README.md) | 将 Git 来源或本地 ZIP 准备为候选插件目录。 |

## 入口与处理步骤

主要入口或定义见 [index.ts](./index.ts)。

先解析来源或市场条目，再下载、解包或准备 Git 工作目录，返回候选目录及来源信息，交给插件校验和安装流程。

## 状态放在哪里

来源准备使用调用方指定的工作目录或缓存目录；最终安装记录由 Plugins 包管理。

## 新代码与测试

根目录保留包入口和分类导航；具体实现放入对应分类。

新增测试放在本目录的 `__test__/`；跨分类用例放在共同目录的 `__test__/`。
