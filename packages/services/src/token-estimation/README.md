# 文本 Token 估算

提供不依赖模型请求的文本 Token 数量估算。

## 入口与流程

调用方使用 `estimateTokens()` 传入文本，获得估算结果供上下文和用量展示使用。

## 状态归属

结果按输入即时计算，不保存长期状态，也不代表供应商实际计费用量。

## 主要文件

| 文件 | 主要接口或用途 |
| --- | --- |
| [index.ts](./index.ts) | 汇总本分类的接口 |

## 测试与维护

纯文本估算规则放在这里，模型真实用量与预算记录交给运行和目标存储处理。

测试放在所属分类同层的 `__test__/`；覆盖多个子分类的测试放在共同上层的 `__test__/`。迁移时同步导入、公开入口、资源地址、文档和旧引用清单。
