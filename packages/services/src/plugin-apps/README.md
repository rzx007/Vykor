# 插件应用记录

保存插件应用的身份、状态、修订及操作归属。

## 入口与流程

PluginAppRepository 校验会话和记录状态，读写应用记录并标记需要持久化的变化，供应用层执行授权和实际操作。

## 状态归属

应用事实位于共享会话状态与 SQLite；进程、页面及可调用权限由宿主管理。

## 主要文件

| 文件 | 主要接口或用途 |
| --- | --- |
| [index.ts](./index.ts) | 汇总本分类的接口 |
| [repository.ts](./repository.ts) | `CreatePluginAppInput`、`PluginAppRepository` |

## 测试与维护

插件应用的持久记录与查询修改放在这里，可信来源核验和运行授权留在 Server 与执行宿主。

测试放在所属分类同层的 `__test__/`；覆盖多个子分类的测试放在共同上层的 `__test__/`。迁移时同步导入、公开入口、资源地址、文档和旧引用清单。
