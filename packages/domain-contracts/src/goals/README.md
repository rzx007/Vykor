# 持续目标契约

定义目标内容、版本、自动运行次数、用量预算、等待原因和操作请求，让目标管理与展示使用同一套数据。

| 文件 | 用途 |
| --- | --- |
| [index.ts](index.ts) | `@vykor/domain-contracts/goals` 公开入口 |
| [records.ts](records.ts) | 目标记录、版本、用量、等待和操作类型及输入上限 |
| [validation.ts](validation.ts) | 创建、修改、暂停、恢复、预算调整及运行方更新请求的解析 |

调用方将未知输入交给对应 `parse*` 函数。函数检查允许字段、标识、版本和数值范围，并复用输入项与附件校验，返回可继续处理的请求。运行方提交的更新不携带可自行决定的目标身份，身份由宿主提供。

目标当前状态、版本冲突处理、预算累计和后续调度由消费方管理，本目录不自动运行或暂停目标。新增目标字段与请求校验放本目录，测试建议放同层 `__test__/`。
