# 用量价格与预算设置

统一模型价格和用量预算的设置数据，供配置读取、计费估算和界面展示共用。

| 文件 | 用途 |
| --- | --- |
| [index.ts](index.ts) | `@vykor/domain-contracts/usage` 公开入口 |
| [settings.ts](settings.ts) | 模型价格、缓存价格、币种、价格来源和预算类型 |

消费方通过 `UsagePrice` 描述采用的模型价格，通过 `UsageSettings` 交换价格列表与预算设置。这里仅定义数据，不查询实时价格、不计算费用，也不执行预算限制。

设置内容、采用时间和实际用量由消费方管理。新增用量设置字段放 `settings.ts`，相关测试建议放同层 `__test__/`。
