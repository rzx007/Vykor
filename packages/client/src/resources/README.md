# 资源接口导航

按业务职责组织访问 daemon 的资源接口。

## 主要文件

| 文件 | 主要导出 |
| --- | --- |
| [index.ts](./index.ts) | 统一导出本分类的类型与函数 |

## 分类目录

| 目录 | 用途 |
| --- | --- |
| [configuration/](./configuration/README.md) | 访问认证、模型提供方、权限、MCP 和系统配置。 |
| [plugins/](./plugins/README.md) | 访问插件、插件应用和插件界面历史，并提供应用展示策略。 |
| [runtime/](./runtime/README.md) | 访问任务、终端和开发运行相关接口。 |
| [session/](./session/README.md) | 访问会话、附件及事件流相关接口。 |
| [workspace/](./workspace/README.md) | 访问项目、笔记、渠道与调度配置。 |

## 入口与处理步骤

主要入口或定义见 [index.ts](./index.ts)。

从本目录入口取得资源接口，再进入会话、插件、配置、工作区或运行资源，实际请求由协议客户端与传输层完成。

## 状态放在哪里

远端业务数据由 daemon 保存；连接、订阅和展示状态保存在客户端对象中。

## 新代码与测试

与本目录职责一起修改的代码放在这里；跨分类的公共入口由上层目录组织。

新增跨分类测试放在本目录的 `__test__/`；只覆盖下级分类的测试放在对应分类的 `__test__/`。
