# 检查文本

用户要求检查文本格式时，将用户提供的原始文本作为 `text` 字段交给 `TextInspectorCheck`，不要提前去除空格、制表符或换行。

1. 阅读 [检查规则](references/rules.md)。
2. 调用 `TextInspectorCheck`，参数仅包含 `{ "text": "用户提供的文本" }`。长度最多为 100,000 个 UTF-16 代码单元；超出时请用户提供较短的一段。
3. 解析返回文本内容块中的 JSON，按 `findings` 的行号和问题代码说明结果。同一行先解释行首问题，再解释行尾问题。
4. `truncated` 为 `true` 时说明只展示前 100 条问题，仍有其他问题。结果为空时说明这两项规则未发现问题，不代表文本在其他方面没有问题。

短文本在支持插件 UI 的 Desktop 中还会提供交互入口。用户可以勾选问题，经主界面确认后调用 `TextInspectorPreview` 生成修复预览。不要替用户自动选择、执行或声称预览已经写入文件；大文本、CLI/TUI 或 UI 关闭时仍按文字结果解释。

此工具只检查传入文本。不要声称它读取了文件、获取了工作区内容或修改了文件；普通检查文字结果不包含原始文本片段，UI 数据和修复预览包含用户传入的文本。
