# 检查规则

- 按 LF（`\n`）分行；检查前移除每行末尾的单个 CR（`\r`），以处理 CRLF 换行。
- `tab-indentation`：行首是制表符。
- `trailing-whitespace`：行尾是空格或制表符。
- 行号从 1 开始；先按行号排列，同一行先返回行首问题，再返回行尾问题。
- 空文本返回空 `findings`。最多返回 100 条问题，只有确实存在第 101 条时才设置 `truncated: true`。
- 输入只允许字符串字段 `text`，最多 100,000 个 UTF-16 代码单元（JavaScript 的 `text.length`，例如一个常见表情占两个代码单元）。

普通检查文字中的问题只包含 `line` 和 `code`，不包含用户原始文本。较短文本的 UI 数据和修复预览包含传入文本，但不会读取或写入文件，也不会启动其他进程。

交互预览只修改所选问题：行首连续制表符逐个换为 2 个空格，行尾空白删除；未选择的内容和 LF/CRLF 保持不变。选项 ID 为 `行号:问题代码`，由预览工具重新检查文本后验证，不接受重复或不存在的选项。
