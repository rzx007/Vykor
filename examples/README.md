# 示例目录

这里保存可阅读、运行和修改的独立示例。每个示例的启动方式、主要文件和状态保存位置见各自说明。

- [像素街区](./pixel-street/README.md)：双击 HTML 即可运行的离线演示，包含车辆行驶、树冠遮挡、拖动和缩放。
- [Agent Reviewer 插件](./plugins/agent-reviewer/README.md)：插件提供 Agent 的最小示例。
- [Notes App 插件](./plugins/notes-app/README.md)：笔记工具与插件界面示例。
- [Text Inspector 插件](./plugins/text-inspector/README.md)：文本检查工具与插件界面示例。

新的独立浏览器演示按主题建子目录；Native Plugin 示例继续放在 `plugins/`。示例自身的检查放在所属目录的 `__test__/`。
