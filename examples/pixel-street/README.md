# 像素街区演示

演示一辆沿环路行驶的小车，经过树冠后方时被遮住。街区、小车和树共用同一套坐标，拖动或缩放时一起移动。

## 直接运行

双击 [index.html](./index.html)，或从浏览器打开此文件。不需要安装依赖、运行构建或启动服务；断网也可运行。HTML、样式和 JavaScript 都保存在这一个文件内。

- 鼠标拖动或单指拖动：平移街区。
- 滚轮或双指捏合：围绕指针或双指中心缩放。
- `−`、`＋`：围绕画面中心缩放。
- 暂停车辆：停在当前时刻观察遮挡。
- 聚焦任一操作按钮后：方向键平移，`+`、`-` 缩放；空格或回车触发当前按钮。

系统启用“减少动态效果”时，页面初始暂停，可手动播放。

## 文件与运行过程

- `index.html`：唯一运行入口。浏览器按文件顺序加载样式、页面、几何计算及绘制交互脚本。
- [`__test__/pixel-street.test.cjs`](./__test__/pixel-street.test.cjs)：路线、缩放锚点、树冠遮挡范围和脚本语法检查。

绘制脚本先生成地面和静态物件，再逐帧更新车辆位置，按前后顺序叠放小屋、车辆和大树，最后统一应用平移与缩放。画面直接画到页面中的 Canvas，也就是浏览器提供的绘图区。

车辆位置、相机位置和播放状态保存在页面内存。操作后会尝试将快照写入浏览器的 `localStorage`，刷新时读取。浏览器禁止本地文件使用存储时，演示仍可操作，刷新后恢复初始状态。数据不发送到服务器。

## 修改入口

所有修改继续放在 `index.html`，计算相关检查放在 `__test__/`。

- 配色与按钮：顶部 `<style>` 的颜色变量和控件样式。
- 斜视角与比例：几何脚本的 `project()`。
- 车辆环路：`routeAt()`；车速在 `tick()` 中调整。
- 树的位置与树冠轮廓：`tree`、`clusters`、`leafAt()`。
- 地面、小屋、树和车辆外观：`groundArt()`、`building()`、`treeArt()`、`drawCar()`。
- 物件前后顺序和相机变换：`render()`。
- 拖动、滚轮、双指与键盘操作：文件后半部分的事件处理。

这是使用代码绘制的虚构街区，无需地图数据或图像生成模型。

## 代码检查

从仓库根目录运行：

```sh
node --test examples/pixel-street/__test__/pixel-street.test.cjs
```

检查覆盖环路闭合、拐角匀速、指针缩放锚点、缩放边界，以及车辆经过实际树冠轮廓的范围。它不验证浏览器画面的样式。
